## 1. V1 现状（已实测，来源=exo-fsr 标定 09-19）

- V1 电路：FSR 上臂（3V3）+ **10kΩ 下臂**（GND），中点 D34；越压读数越高（正逻辑）；
- 标定结论：**0.3–5N 适用，>5N 近饱和**；
- 近饱和的电路解释：5N 时 R_FSR 已降到几 kΩ 量级，远离 10k 对称点 → 输出爬向 2.75V+ 后变化率骤降（下节）。

## 2. 核心数学：分压器的「瞄准」性质

中点电压（R_f=固定电阻，R_F=FSR）：

$$V_{out} = 3.3 × \frac{R_下}{R_上 + R_下}$$

对 R_F 取对数斜率，**斜率最大点在 R_F = R_f（对称点，此时 V_out = 1.65V = 半电源）**。推论（这就是「R_f 选择=瞄准哪段力」）：

```
R_f = 10kΩ  → 灵敏度集中在 R_FSR~10k 段  → 轻压（指尖级，0.3–5N）✅ V1 验证
R_f = 330Ω  → 灵敏度集中到 R_FSR~330Ω 段 → 重压段（鞋内站立/行走）
```

鞋内要测的不是指尖：站立时脚掌局部压力是几十牛顿级 → R_FSR 被压进 <1kΩ 区 → **330Ω 是把「瞄准镜」从轻压段挪到重压段的那个选择**。FSR 的 R-F 是幂律（每约十倍力降约一个数量级电阻，数据手册口径），所以电阻换一个数量级 ≈ 量程挪一个力级。

## 3. V2 拓扑（按 09-19 拍板：330Ω 上臂）

拍板字面：**330Ω 上臂（3V3 侧），FSR 下臂（GND 侧）**——与 V1 上下互换。两种拓扑对称点电压相同（数学事实），差别在**方向**：

| R_FSR | 无压 >10M | 10k | 1k | **330（对称点）** | 100 |
|---|---|---|---|---|---|
| V1（FSR上/10k下）读数↑压 | ≈0 | 1.65V | 2.75V | — | — |
| V2（330上/FSR下）读数↓压 | ≈3.3V | 3.19V | 2.48V | **1.65V** | 0.77V |

V2 是**反逻辑：越压读数越低**，鞋内波形里站立相=下陷。一个可能的工程好处【AI 推测，09-19 拍板理由待原会话确认】：无压时读数≈满值（4095），掉到 0 附近=断线/短路自检信号。软件只看相对形状，反逻辑无碍。

## 4. 回路电流账（V1 课同款检查，口算级）

- 最大电流：R_FSR 压到 ~100Ω 时 I = 3.3/(330+100) ≈ **7.7mA**（V1 是 0.28mA，大一个量级但仍是小信号）；
- 330Ω 上功耗：I²R ≈ 19.6mW ≪ 1/4W 额定——电阻安全；
- **预习课提出的观察点【AI 设定，动手时验证】**：导电聚合物 FSR 长时间通毫安级电流有自热可能（Interlink 手册有最大电流密度建议）——V2 鞋内是长时间连续承重场景，**动手时留意静止站立 2–3 分钟读数有无缓慢单向漂移**（区分自热 vs 蠕变：松开载荷看回不回）。

## 学习过程（2026-09-24，会话陪学完成，口算两题全过 → 0.7）

- **对数灵敏度推导**（用户主动追问「取对数斜率是不是微积分」）：现场推 dV/dlnx = E·x/(1+x)²，峰值 x=1、峰值 0.825 V/ln单位 ≈ 1.9 V/decade；配图 `notes/ch02_对数灵敏度曲线.html`（两面板：灵敏度钟形平移=瞄准镜挪量程 / 传输曲线两拓扑镜像交于半电源）+ 电路图 `exo-fsr` 仓 `web/v2_topology_a.png`（http 服务 8322）。
- **幂律 vs 指数辨析**（用户问「指数常数多大」）：纠正方向（R ∝ F^(−a)，力↑电阻↓，非 F² 上长）；a≈1（电导∝力，Interlink 手册口径，<100g 为死区）；「斜率看机制、平移看几何」——同家族斜率一致、换型号系数变必须重标【AI 补充待确认】。
- **原创表述**：「V_out(F) = S(log R(F))」复合函数视角——FSR 先把力映成 log R（反向直线），分压器再把 log R 映成 V（S 曲线），钟形是 S 曲线的斜率剖面。做软件换算（电压反推力）时直接用。
- **口算题1（对称点）**：两拓扑均 1.65V，机制=分压输出只看两臂比值，R_FSR=R_f 时比值=1 不随换位变。两处修正后收口：①精确值 1.65V 非「1.7 左右」（基准锚点必须存精确值）；②拓扑 A 中点接 GND 侧 FSR，ADC 测的是 FSR 电压非 330（画图后用户自述「ADC 一端接地测引脚对地」补上盲区，并正确推演对调版方向）。
- **正/反逻辑判表**（口算题1 延伸，用户推演正确）：逻辑只看 FSR 在上（正：越压越高，空载≈0）还是在下（反：越压越低，空载≈4095），与阻值无关；V2 选 FSR 下的工程理由=空载满值+掉零的故障特征【AI 推测待实测确认】。
- **口算题2（量程/速判法）**：R_f = 目标工作阻值（V3 用 100Ω）；速判法 why = 钟形峰落在 R_F=R_f（斜率最大）+ 对称点分压一半（2048）上下有余量。全过。
