## 概念定义

**【材料】**（main.py 结构，出处 exo-fsr 仓 main.py + ch03 课 §2）

```python
# 出生段（跑一次）：ADC 三行配置 + 蓝牙②③④段配置
adc = ADC(Pin(34)); adc.atten(ATTN_11DB); adc.width(WIDTH_12BIT)
# 一生段（跑到断电）：
while True:
    line = f"{ms},{adc.read()}"   # 读+拼行
    print(line)                    # USB 串口
    （连接态：蓝牙 notify 同一行）
    time.sleep_ms(10)              # 每轮 ≈10–13ms → ~100Hz
```

- **规律一**：初始化只跑一次、`while True` 占满余生——「改行为」改循环、「加功能」在出生段加配置。
- **规律二**：采样率=时间预算。`sleep_ms(10)`=每 10ms 产出一行（非「采 10ms 的数据」）；每轮固定开销（读/拼/打印/notify）会吃掉预算——10-03 加 BLE 后实测掉到 66–79Hz，是开销变长非 sleep 变化。
- 采样率需求锚点：脚部动作几 Hz、触地冲击上升沿几十 ms（报告 20260910 §9.1）→ 100Hz 是「让几十 ms 瞬态至少落几个点」的底线。
