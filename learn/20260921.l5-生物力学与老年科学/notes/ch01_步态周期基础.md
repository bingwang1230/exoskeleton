# 第 1 课：步态周期基础（2026-09-21，出差学习包）

> 10–15 分钟手机课。来源纪律：本课为教科书级常识口径（Perry & Burnfield《Gait Analysis: Normal and Pathological Function》为步态分析标准参考）；具体数值惯例逐处标注，凡「AI 引述惯例，待确认原文」= 未核对原始文献。

## 1. 一个周期：从同侧足跟着地开始

**步态周期（gait cycle）** = 同一只脚**足跟再次触地**之间的全部动作。教科书口径：一个周期约 1.0–1.2 秒（自然步速），分两相：

- **站立相（stance）≈ 60%**：这只脚在地面上承重；
- **摆动相（swing）≈ 40%**：这只脚离地向前迈。

比例 60/40 是自然步速下的近似（教科书口径）；步速越快，摆动占比越大——跑步时双支撑期归零，这就是走路和跑步的分界定义。

## 2. 三个关键事件 + 双支撑期

不用背八个分期（那是临床版本），记住三个事件就够用：

| 事件 | 时刻（%周期） | 含义 |
|---|---|---|
| **HC** 首次触地 | 0% | 足跟着地，承重开始 |
| **FO** 足尖离地 | ≈60% | 该脚蹬离，摆动开始 |
| **对侧 HC** | ≈50% | 另一只脚触地 |

**双支撑期（double support）**：一头一尾两段（开头 ~0–15% 与结尾 ~50–60%；11-11 勘误：原记「40–60%」有误，起点是对侧足跟着地 50% 不是 40%），双脚都在地上——它是走路最稳的时段（重心可以随便交给任何一只脚）。**步速↑ → 双支撑期占比↓**（慢走 25% 上下，快走趋近 10% 量级，方向确定、具体数字 AI 引述惯例待确认；跑步 = 0）。

## 3. 三个量：步长、步频、步速

$$步速 = 步长 × 步频$$

- **步长（step length）**：一只脚的足跟到**另一只**脚足跟的纵向距离（左右各算一步）；**步幅（stride length）**才是一个整周期的左右合计。这俩文献里常混用，读论文先看定义。
- 老年人常用的步速分界：**1.0 m/s**——文献里常见「<1.0 m/s 视为步速受限」的分界（AI 引述惯例，出自老年综合评估常用口径，待确认原文综述）。

## 4. 老年步态长什么样（连接项目叙事）

教科书级特征（自然衰老，非病理）：

- 步速↓（步长贡献为主，步频变化小）；
- 双支撑期占比↑（稳态优先）；
- 步宽略↑（支撑面加宽）；
- 合称**谨慎步态**：用「慢+稳」换安全余量。

⚠️ **词库纪律提醒**（三线计划 §1.3）：这些特征对外的讲法是「**自主起居的行动余量**」叙事——「腿脚的余量是可以量出来的」，**不出现**防跌倒/康复/疗效宣称。学习笔记内部怎么严谨怎么来，出口时过词库。

## 5. 落到我们的波形上（对接 L3 / exo-fsr / Phase 3）

FSR 鞋内实测（T-017）看到的波形，就是这只脚的**站立相压力包络**：

```
ADC
 │      ┌─────站台：站立相（承重爬升→平台→蹬离衰减）
 │     /│      ││\
 │    / │      ││ \___ ← 足尖离地后贴地残压→0
 │   /  │      ││
 └──┴───┴──────┴┴────────→ t
   HC            FO
```

- 站立相≈周期的 60% → 鞋内波形「高电平」应占约六成（可当验证：实测波形高占比明显偏离 60%，要么走得不自然，要么传感器位置偏了）；
- 双支撑期 = 波形中「本脚已承重但重心尚未完全交过来」的缓升段 + 蹬离前的缓降段；
- **FSR 当相位传感器，不当测力仪**（回扣 V1 标定三脾气：非线性/迟滞/漂移 → 信形状不信绝对值）——判断「脚在哪一相」不需要牛顿数，需要清晰的事件边沿。这正是 OpenExo 用 FSR 判相位、也是我们 Phase 3 L4「步态相位检测 IMU 阈值法起步」的前置直觉。

## 拓展讨论（11-11）：临床八分期 + 虚步 vs 摔倒式步行

### 临床八分期（Perry & Burnfield，百分比为教科书口径）

站立相拆 5 段：①初始触地 0%＝工程 HC；②承重反应期 0–12%（接住体重，膝屈缓冲）；③支撑中期 12–25%（倒立摆滚过支撑脚上方）；④支撑末期 25–50%（足跟抬、体重滚到前掌）；⑤摆动前期 50–62%（对侧已落地，本脚蹬离）＝双支撑第二段。摆动相拆 3 段：⑥摆动初期 62–75%；⑦摆动中期 75–87%（小腿摆过支撑腿）；⑧摆动末期 87–100%（减速摆好）。

- **两套坐标系**：临床八分期＝病历语言（每期对应可检查的肌肉活动/关节角，诊断坐标系）；工程事件边沿＝控制坐标系（锁相助力只需「哪只脚哪个大相」）。造外骨骼住后者，但读 OpenExo/临床文献术语全来自前者。
- **用户自答**：谨慎步态多出的双支撑时间主要堆在**承重反应期**（变长）——正确。

### 虚步 vs 摔倒-接住（用户提出，合气道/接触即兴经验合成）

- 普通走＝倒立摆+被动动态行走（McGeer 1990 起，AI 引述惯例待确认）：重心在支撑脚前被推出去，每步都是受控摔倒+下一脚接住，钟摆交换回收能量，**落脚与承重焊死、流水线不可逆**。
- 虚步＝**触地与承重解耦**，插入医学分期表里不存在的中间态「接触未承重」（脚已触地、重心未过，双支撑拉长到秒级、左右负载极端不对称如 95/5，可逆——探了可收回）。
- 医学视角：谨慎步态的极端版，loading response 拆成试探+真承重两截；从动态稳定退化为**准静态稳定**（重心不出旧支撑面）；代价＝能量（稳定性用代谢账单买）。谱系：跑步(双支撑=0)←普通走(~20%)←老年谨慎步态(↑)←冰面虚步(准静态极端)。
- 工程视角：**虚步让阈值相位检测器失明**——探步脚跟信号低于站立门限（p95×0.3 档），状态机判定「什么都没发生」；这正是 T-041（转身碎步失明）的第一性解释。要认它需降门限+加「接触/承重」两态，或连续相位估计（回到 e2e 的范式演进线）。
- 留了一道预测题（未答）：右脚虚步时右脚跟曲线形态 + 左脚曲线同时段变化。答后补记。

## 学习过程（2026-11-11，清零重学一轮完成）

> 用户要求重学；账本清零（旧分见 PROGRESS 存档注），六层重讲：周期定义→60/40→事件与双支撑→步速公式→老年步态→FSR↔相位+实操。

- **120% 推演二次自发复现**；追问「50/50 会怎样」答「一瞬双脚腾空」＝从第一性原理推出走路/跑步分界（双支撑归零+腾空），未提示。
- **术语修正两处**：「自由落体」→**弹道式摆动**（ballistic swing，钟摆类比；摆动时长相近故提速主要压缩交接段）；「三角支撑」→步长增大则**关节力矩与蹬伸功率需求增大**（老年缩步长的力学解释）。
- **步速估算对账**：自估 100m/60s→报 1.4 m/s，实算 1.67（跳了除法套了惯例数）；教训句「感觉不可靠，所以要量」（帖⑤候选叙事点，入 T 账）。
- **步频定义陷阱（纠错）**：目测周期 1.5s→报步频 40——那是 **strides/min**；按本课定义（步频＝每分钟 step 数，step＝一只脚到另一只脚）应 ×2≈80，算法机读 75 步/分。
- **实操目测 vs 算法对账（walk_pad.csv 5–17s 窗）**：用户目测左 HC 5.1/6.6s、FO 6.1s、周期 1.5s、站立占比 66%；analyze_gait.py 机读：周期中位 1.50s（**与目测完全一致**）、左站立中位 0.88s 占比 59%、步频 ≈75 步/分、左右对称差仅 50ms。目测事件定位准，占比估计偏粗（两目测时刻相减放大误差）——「信号边沿定位事件」已上手。
- **老年步态**：结论全对、力学内核自摸；词库演练不考（用户明确：学习记录无需对外文案，发布时再过闸）。

## 学习过程（2026-09-24，会话陪学完成）

- **120% 推演（用户原创，亮点）**：双脚站立相各 60% → 全身站立时长合计 120% 周期 → 超出的 20% 就是双支撑期。独立从占比推出双支撑的存大，教科书未如此讲。
- **跑步边界**：双支撑归零 + 腾空阶段 → 单脚站立相 < 50%。用户答对并给出了「为什么是定义性分界」。
- **术语确认**：HC = Heel Contact 足跟着地（传统名 heel strike「跟击」，Perry 标准术语 initial contact）；FO = Foot Off 足尖离地（传统 toe off）。爬升→平台→衰减 = HC→FO 完整站立相 ≈60%，用户确认理解。
- **一处滑误自纠**：双支撑先答「中段」，随即自纠「一头一尾各 ~10%」——中段是单支撑（对侧脚摆动经过）。按协议自纠成功计入 0.7 档。
- **迟滞 ≠ 延迟（纠正）**：用户答「FSR 会延迟」——迟滞是同力异读（加载/卸载路径不同，复放 ±2–3%），不是时间滞后。FSR 响应延迟（毫秒级）另有其事但不是判相位的主要障碍。
- **硬件洞察（待记入 V3 设计）**：单脚需要脚跟一片 + 前掌一片 FSR——脚跟片信号起=HC，前掌片归零=FO，两片把站立相两端事件分开。当前 V2 单片只能看到包络，双片是 V3 攀岩鞋版的候选设计。
