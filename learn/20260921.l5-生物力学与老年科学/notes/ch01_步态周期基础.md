# 第 1 课：步态周期基础（2026-09-21，出差学习包）

> 10–15 分钟手机课。来源纪律：本课为教科书级常识口径（Perry & Burnfield《Gait Analysis: Normal and Pathological Function》为步态分析标准参考）；具体数值惯例逐处标注，凡「AI 引述惯例，待确认原文」= 未核对原始文献。

## 1. 一个周期：从同侧足跟着地开始

**步态周期（gait cycle）** = 同一只脚**足跟再次触地**之间的全部动作。教科书口径：一个周期约 1.0–1.2 秒（自然步速），分两相：

- **站立相（stance）≈ 60%**：这只脚在地面上承重；
- **摆动相（swing）≈ 40%**：这只脚离地向前迈。

比例 60/40 是自然步速下的近似（教科书口径）；步速越快，摆动占比越大——跑步时双支撑期归零，这就是走路和跑步的分界定义。

## 2. 三个关键事件 + 双支撑期

不用背八个分期（那是临床版本），记住三个事件就够用：

| 事件 | 时刻（%周期） | 含义 |
|---|---|---|
| **HC** 首次触地 | 0% | 足跟着地，承重开始 |
| **FO** 足尖离地 | ≈60% | 该脚蹬离，摆动开始 |
| **对侧 HC** | ≈50% | 另一只脚触地 |

**双支撑期（double support）**：0–15% 和 40–60% 两段，双脚都在地上——它是走路最稳的时段（重心可以随便交给任何一只脚）。**步速↑ → 双支撑期占比↓**（慢走 25% 上下，快走趋近 10% 量级，方向确定、具体数字 AI 引述惯例待确认；跑步 = 0）。

## 3. 三个量：步长、步频、步速

$$步速 = 步长 × 步频$$

- **步长（step length）**：一只脚的足跟到**另一只**脚足跟的纵向距离（左右各算一步）；**步幅（stride length）**才是一个整周期的左右合计。这俩文献里常混用，读论文先看定义。
- 老年人常用的步速分界：**1.0 m/s**——文献里常见「<1.0 m/s 视为步速受限」的分界（AI 引述惯例，出自老年综合评估常用口径，待确认原文综述）。

## 4. 老年步态长什么样（连接项目叙事）

教科书级特征（自然衰老，非病理）：

- 步速↓（步长贡献为主，步频变化小）；
- 双支撑期占比↑（稳态优先）；
- 步宽略↑（支撑面加宽）；
- 合称**谨慎步态**：用「慢+稳」换安全余量。

⚠️ **词库纪律提醒**（三线计划 §1.3）：这些特征对外的讲法是「**自主起居的行动余量**」叙事——「腿脚的余量是可以量出来的」，**不出现**防跌倒/康复/疗效宣称。学习笔记内部怎么严谨怎么来，出口时过词库。

## 5. 落到我们的波形上（对接 L3 / exo-fsr / Phase 3）

FSR 鞋内实测（T-017）看到的波形，就是这只脚的**站立相压力包络**：

```
ADC
 │      ┌─────站台：站立相（承重爬升→平台→蹬离衰减）
 │     /│      ││\
 │    / │      ││ \___ ← 足尖离地后贴地残压→0
 │   /  │      ││
 └──┴───┴──────┴┴────────→ t
   HC            FO
```

- 站立相≈周期的 60% → 鞋内波形「高电平」应占约六成（可当验证：实测波形高占比明显偏离 60%，要么走得不自然，要么传感器位置偏了）；
- 双支撑期 = 波形中「本脚已承重但重心尚未完全交过来」的缓升段 + 蹬离前的缓降段；
- **FSR 当相位传感器，不当测力仪**（回扣 V1 标定三脾气：非线性/迟滞/漂移 → 信形状不信绝对值）——判断「脚在哪一相」不需要牛顿数，需要清晰的事件边沿。这正是 OpenExo 用 FSR 判相位、也是我们 Phase 3 L4「步态相位检测 IMU 阈值法起步」的前置直觉。

## 学习过程（2026-09-24，会话陪学完成）

- **120% 推演（用户原创，亮点）**：双脚站立相各 60% → 全身站立时长合计 120% 周期 → 超出的 20% 就是双支撑期。独立从占比推出双支撑的存大，教科书未如此讲。
- **跑步边界**：双支撑归零 + 腾空阶段 → 单脚站立相 < 50%。用户答对并给出了「为什么是定义性分界」。
- **术语确认**：HC = Heel Contact 足跟着地（传统名 heel strike「跟击」，Perry 标准术语 initial contact）；FO = Foot Off 足尖离地（传统 toe off）。爬升→平台→衰减 = HC→FO 完整站立相 ≈60%，用户确认理解。
- **一处滑误自纠**：双支撑先答「中段」，随即自纠「一头一尾各 ~10%」——中段是单支撑（对侧脚摆动经过）。按协议自纠成功计入 0.7 档。
- **迟滞 ≠ 延迟（纠正）**：用户答「FSR 会延迟」——迟滞是同力异读（加载/卸载路径不同，复放 ±2–3%），不是时间滞后。FSR 响应延迟（毫秒级）另有其事但不是判相位的主要障碍。
- **硬件洞察（待记入 V3 设计）**：单脚需要脚跟一片 + 前掌一片 FSR——脚跟片信号起=HC，前掌片归零=FO，两片把站立相两端事件分开。当前 V2 单片只能看到包络，双片是 V3 攀岩鞋版的候选设计。
