# 第二章概念 3：力臂的解剖学劣势——为什么肌肉出力远大于外部载荷

> 日期：2026-10-10（通勤学习，AI 出题，用户手算）。类型：概念型（含口算检验）。

## 核心：两个力臂差一个量级

- **肌肉侧**：股四头肌绕髌骨、经髌腱挂胫骨结节，附着点离膝轴仅 ~4-5 cm（文献典型值，待确认）。
- **载荷侧**：外部力作用在环节末端，作用线离关节轴几十 cm（例：单腿下楼 GRF 500 N、载荷臂 ~30 cm）。
- 静力平衡 → **肌力 = 载荷 × (载荷臂/肌力臂)**，比值即放大倍数。

## 用户检验（2026-10-10，✓）

- 力矩 = 500×0.30 = 150 N·m；肌力 = 150/0.045 = **3333 N**（≈载荷的 6.7 倍）。
- 框架助力点 5 cm→20 cm，力臂×4，同样助力量出力 **1/4** ✓。

## 理解要点

- **关节接触力大不是人重，是杠杆逼的**：肌力同时压关节面——膝接触力日常 2-3 倍体重、深蹲到底可达 ~7 倍（文献典型值，待确认）。
- **费力杠杆是故意的**：肌腱附着近轴 → 肌肉短行程换关节大转角大角速度；代价是力放大近十倍。生物用「力不值钱（肌肉可练粗）」付账。
- **外骨骼的接口**：机器无解剖约束，框架可把作用点放远——力臂放得好，同样助力矩电机可小一号；第五章「助力比 10-30%」的分母正是被此劣势放大后的生理力矩。
