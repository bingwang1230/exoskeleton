# 概念 4：为什么单关节外骨骼可以先按平面（矢状面）处理

> 日期：2026-10-10（通勤口述，AI 整理）。类型：概念型。掌握判定：讨论确认 ✅。

## 用户的核心论证（2026-10-10 口述）

1. **限位结构是近似的根据**：膝关节的关节限位（韧带+肌腱）使左右晃动范围本来就很小，可以近似看成只有一个自由度的关节——平面简化的合理性来自解剖结构，不是数学偷懒。
2. **日常水平面运动另有来源**：走路中脚/小腿在水平面上的朝向变化主要是髋关节贡献的自由度，不破坏膝的矢状面近似。
3. **反例域（近似的边界）**：
   - 攀岩挂脚、折膝：主动利用关节限位本身做动作，膝承受侧向力矩；
   - 合气道/巴西柔术反关节技术：刻意对关节非自由度方向施加力矩；
   - 摔跤、磕绊：意外侧向力矩。
   - 共同点：日常步态少见，集中在「故意用限位」或「失控」两类场景。
4. **推论**：关节限位依赖韧带和肌腱，这些组织并不像骨骼那样抗压——侧向力矩正是膝损伤的典型来源。

## AI 补充（常识级解剖学，待确认；不属用户口述）

- 膝并非严格单自由度：伸直末端有「锁扣机制」（screwing home）——胫骨小幅内旋约 5–10°，屈膝时回旋——即正常步态内也存在小范围旋转自由度，量级小，不破坏平面近似。
- 工程判据的准确表述：助力目标是矢状面伸展力矩，正常步态下额状面/水平面分量相对小（具体比例数据待查，暂不引入数字），所以**估算阶段**用平面模型够用；**结构设计阶段**不能沿用——外骨骼机械腿若在侧向也把膝限死，摔跤磕绊时侧向冲击会经框架传到别处或加剧限位受力（安全相关）。
- 与本项目联动：V3 攀岩脚法量化中，折膝/挂脚正是「非矢状面动作依赖关节限位」的实例——数据解读时膝的侧向载荷是真实工况，不是伪影。

## 结论

平面（矢状面）简化 = **单自由度铰近似**，其合法性来自膝的解剖限位；失效场景 = 主动利用限位（攀岩/格斗技）与意外侧载（摔跤/磕绊）。外骨骼设计要注意：分析可以平面化，结构不能把侧向自由度也刚性接管。
