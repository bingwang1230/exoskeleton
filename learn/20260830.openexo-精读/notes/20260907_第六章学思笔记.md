# 第六章学思笔记：控制方案（P1 复现的核心章）

> 2026-09-07 收官。五概念全过：步态相位估计 0.7 → 髋样条控制器 0.65 → 步态周期与肌肉账本 0.5（前置坐标系）→ 踝 PJMC 0.6 → 低层闭环 0.65。

## 本章的用户轨迹

1. **读图反向与坐标系重建**：把 84% 读成归零点（实为出发点）→ 打烊比喻失败 → 零比喻时间轴表格重讲 → 用户主动要 HTML 可视化 → 三连周期交互图 → **用户两次目检抓出问题**（84/92 标注重叠、肌肉条渲染 bug——width NaN）——目检能力成为学习闭环的一部分
2. **肌肉账本混淆与自纠**：把腓肠肌/胫骨前肌（踝账本）混进髋伸屈 → 时间轴表格+肌肉映射重讲后自通；「腓肠肌拉长→收缩」直觉正确只是位置放错（实为跟腱弹簧）
3. **比喻失效教训**（讲解侧）：媒婆/账本/打烊连续使用后崩盘，用户明确反馈「打烊更难理解」——时间机制类内容改用时间轴表格+交互可视化+肌肉映射
4. **设计追问三轮升级**：站立问题自推出（踝无周期概念）→「靠结构支撑」撞回第一章分类法 → 为什么踝不加跟 FSR（需求精度×成本）→ 100% 缩放自提**人机力量配比**视角
5. **跨域直通桥**：接触即兴 body-mind（Nita Little）→ 外骨骼快回路设计原理——「好的助力=好的舞伴」，用户带来的连接
6. **祛魅时刻**：机甲幻想 vs 兼容走跑都难——用户点名入库 T-022，且自己给出出口（「现实从当下能实现的角度设计」）

## 用户自产清单（对比 AI 讲解）

- 「直线力矩连续但一阶导不连续，让一阶导连续，机械给的力就不会突然变化」（样条，全对）
- 「误差遇见零幅值就没有发言权」语境下的读法+「缩放比例=人机力量配比」（T-021）
- 「机甲是远期，现实从当下能实现的角度来设计」（T-022）
- 六问全对一轮（loading 双支撑/等长过渡/heel-off 40%/蹬离/摆动/跟击信号）
- 踝改 10ms 判断全对；I 刚需才加的自洽判断

## 讲解侧教训（写给未来的自己）

- 比喻是易耗品：同一个会话里最多一两个，时间机制题用时间轴表格+数值轨迹
- AI 无图像输入时：数值断言自检（NaN/关键帧/几何越界）+ 截图交用户终检——本次连环抓出 3 个渲染 bug（容器缺失/el 3 参写死/肌肉条 width NaN）
- 「跟击 vs 状态开关」的构型归属要第一天就画架构表，不能事后补

## 对 P1 的净输出

- PJMC 唯一必须自己校准的算法环节：系数迁移靠硬件对齐，缩放手调代金标准，inline 自洽当烟雾报警器
- 必自补的安全件：站立检测（FSR 恒定）、相位表看门狗、FSR-τ* 交叉校验
- treadmill 增益整定是必须亲手摸的技能
- 架构账本系列金句闭环：远端减重→弹性链→带宽降→大 D→65ms——每笔架构决策在控制层回账
