# 硬件第一课：从购物车学起——电压、分压、ADC 与数据链路

> 2026-09-10 会话产出。背景：用户硬件零基础，FSR 下单前被淘宝参数卡住（「大量参数不知道选哪种」）——AI 改从常识讲起，购物车核验即第一课教材。掌握度：0.3–0.4（保守，待到货实操验证，见 PROGRESS 备注）。

## 概念定义

### 1. 电压 / 电流 / 电阻 与欧姆定律

**【AI 补充（教学类比）】**水路类比：电压 V = 水压差，电流 A = 水流大小，电阻 Ω = 水管粗细；管越细（电阻越大）同水压下水流越小。欧姆定律 `V = I × R` 是本阶段唯一公式。

### 2. FSR = 会变的电阻

**【材料】**无载电阻 >10MΩ，重压最低约 2kΩ 量级，压得越重电阻越小；两线器件无极性（Interlink FSR 400 系列数据手册 PDS-10004-C，materials/）。
**【AI 补充】**直觉：一片「电阻可变的海苔」——问题：电脑读不懂电阻，只懂电压数字，需两步翻译。

### 3. 分压电路：电阻→电压的翻译

**【AI 补充（推导，可裸重演）】**两电阻串联分 3.3V，中点电压 = 3.3V × R_下/(R_FSR + R_下)。取 R_下 = 10kΩ 固定电阻：

```
3.3V ────[ FSR ]────●────[ 10kΩ ]──── GND
                    └──→ 中点 = 信号
```

| 状态 | FSR 电阻 | 中点电压 |
|---|---|---|
| 没压 | >10MΩ | ≈0.003V |
| 轻压 | 10kΩ | 1.65V |
| 重压 | 2kΩ | 2.75V |

### 4. ADC 与采样率

**【材料】**ESP32-D0WD：12 位 SAR ADC，0–3.3V → 0–4095，多通道（选型页，已购 DevKit V1 30Pin）。
**【AI 补充】**12 位 = 2¹² 档 = 4096 档；采样率选择：脚部动作几 Hz、触地上升沿几十 ms → 100Hz 有 5–20 个点在上升沿上，够画斜率（体重秤只有几 Hz，干不了这事）。

### 5. MCU 与数据链路

**【AI 补充（链路图，背下即通）】**

```
[压力] → [FSR] →(2线)→ [面包板分压] →(1信号线)→ [ESP32 ADC] → USB/WiFi → [电脑 Python 实时曲线]
```

软件人翻译：传感器=输入设备（鼠标）、分压=信号翻译层、ADC=采样器、ESP32=无屏迷你电脑、串口/WiFi=IO 总线。「你缺的不是电子学，是一条还没用过的外设总线。」

**面包板**：中缝左右分家；每半排 5 孔互通；两侧电源轨整列竖通；免焊。

## 学习过程

@2026-09-10
- **初始理解**：用户自述「对硬件完全陌生」，直接看淘宝参数无从下手（上一轮 AI 给的清单「超纲」——责任在 AI 跳步，非用户误解）。
- **关键讨论**：①杜邦线长（30cm 通吃桌面+上鞋）、②电阻功率（1/4W vs 1W/2W/3W「备将来」——纠正：信号电路功耗 0.8mW，1/4W 裕量 300 倍；大功率≠兼容性好，是体积大；将来电机课要的是毫欧采样电阻等完全不同的东西）、③EVA 厚度（2mm：保护优先，膜厚仅 0.375mm；压实毫秒级 vs 脚加载几十毫秒，上升沿保留、对比公平）、④**攀岩鞋无鞋垫**（用户领域知识纠偏 → V3 改外底粘贴方案）。
- **独立产出**：暂无（待到货实操 V1——接线/刷固件/见波形，即本课的操作型裁判）。

## 关键洞察

- 压力 → 电阻 → 电压 → 数字，两次翻译一次采样，链路图一张讲完。
- 量程饱和的诚实边界：官方量程 ~0.2–20N，踮脚单点 >50kg 常见 → 顶格；「贴脚 vs 砸脚」的分野在触地最初几十毫秒的爬升段（形状可辨）——与 OpenExo「信形状不信绝对值」同路（learn/openexo-精读/notes/ch05_传感器布局.md）。
- 购物车就是教材：参数卡住的地方=概念缺口的精确坐标。

## 附录：工位与收纳方案（2026-09-10 定，¥0–50 两档）

- **第一档（¥0–20，今天能做）**：①家里现有透明分格盒先分 7 类件；②自封袋细分——电阻按阻值一袋（100 只倒格子必混）、FSR 每片独立小袋防引脚互刮（膜面娇贵）；③干燥剂两包（零食/药瓶攒）防潮——金属引脚、USB 口怕锈；④纸胶带+记号笔标签（电阻袋直接写「10K 1/4W」，色环难读）；⑤面包板背胶贴旧鼠标垫/硬板成「工作板」，ESP32 排插旁边——收纳=整板端走。
- **第二档（¥20–50，可与电机件合单）**：分格可调零件盒（淘宝搜「零件盒 分格可调」，¥15–30，隔板可拆优于固定格）+ 魔术贴扎带卷杜邦线（¥5–10）+ 小标签贴纸（¥5）。
- **纪律三条**：一物一格用完归位（硬件找不到=项目停滞）；板子不叠放（排针刮花焊点）；电池不进密封盒不暴晒。
- **ESD 边界**：这批均不敏感（FSR 数据手册明示 Not ESD Sensitive；电阻不敏感；ESP32 普通级）——常规习惯够用（摸板前摸金属放静电）；将来买驱动器/芯片的铝箔快递袋留用。
