L3 实操首课 · V1 桌面版接线图 v2（ESP32 平放桌面版）

你的板长针朝下、板面上方只有短头——所以 ESP32 不插面包板，平放桌面（针朝下顶桌面没事，桌面不导电），三根公母线母头直接套长针。
红 = 3.3V 供电 黑 = GND 共地 黄 = 信号（中点电压 → D34） FSR 10kΩ 电阻 18 列 = 中点 ●
步骤做什么件
⓪ESP32 轻轻拔下面包板（左右摇晃着拔，别硬拽），平放桌面—
①红母头套 3V3 针（= USB 口同侧、从 USB 数第 1 根）→ 红公头插顶轨外行公母线
②黑母头套 GND 针（= USB 口同侧、从 USB 数第 2 根）→ 黑公头插顶轨里行公母线
③FSR 一脚 → 顶轨外行；另一脚 → 18 列直插
④10kΩ 一脚 → 18 列（与 FSR 脚同列）；另一脚 → 顶轨里行直插
⑤黄母头套 D34 针（丝印 34；= 另一排、从 USB 数第 13 根，旁边 39/36 别认混）→ 黄公头插 18 列公母线
认针诀窍：针朝上后丝印看不见了，所以先丝印朝上认一遍、记住「从 USB 数第几根」，再按数数找针——USB 口最好认，数错重来就是，不怕。
上电前三查：① 18 列里 FSR 脚 + 电阻脚 + 黄线三个东西在同列；② FSR/电阻另一端分别在 3.3V 行和 GND 行，没互换；③ 母头套紧了、没碰到相邻针。查完才插 Type-C。
