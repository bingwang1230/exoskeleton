# 第 1 课：范式转变——task-specific 到 task-agnostic（2026-09-21，出差学习包）

> 10–15 分钟手机课。来源：全部依据 `reports/20260919.端到端任务无关外骨骼控制调研.md`（其题录已逐字核对）与 Shepherd 2026 roadmap 网页快照（摘要+112 条引文，正文在付费墙内——**我们没读过正文**，本课只讲快照与 OA 全文能撑住的部分，越界处显式标注）。

## 1. 一句话版本

外骨骼控制正从「**每个任务配一个厨师**」（task-specific）转向「**读懂你想吃什么，直接做**」（task-agnostic）——统一控制信号 = **生物关节力矩的连续估计**（人自己想出多少力，机器实时估出来）。

## 2. 上一代：task-specific + HIL 优化

代表（题录核对自 roadmap 引文表）：

- Zhang, J. et al., *Science* 357:1280 (2017)——HIL（human-in-the-loop）优化**平地行走**助力曲线参数的开山作；
- Slade, P. et al., *Nature* 610:277 (2022)——现实世界版个人化助力。

工作方式：把「任务」当离散类别（平地走/上楼/跑步），每类分别采集 + 优化助力参数，靠分类器先判「现在在哪个任务」。

**根本局限**（roadmap 摘要口径）：人的运动本质**连续、无限可变**——真实世界里任务不可枚举，每换一类就要重新调参，部署不出去。

## 3. 新范式：task-agnostic = 估计力矩

开山（题录核对，非 OA 未读全文）：Molinaro, D. D. et al., *Nature* 635:337 (2024) "Task-agnostic exoskeleton control via biological joint moment estimation"。

核心论证链（roadmap 摘要口径）：

```
不再显式分类任务
   ↓
连续估计「生物关节力矩」（人自身想出的力矩，区别于外骨骼输出的力矩）
   ↓
任务信息隐含在力矩里（上楼时髋力矩模式自然和平地不同——不需要告诉机器你在上楼）
   ↓
估计值直接映射为助力 → 任务无关
```

注意方向性：**力矩是果也是因**——它是所有任务的统一「中间语言」。

## 4. 三大未决挑战（roadmap 摘要原文口径，= 综述 §4–6 骨架）

1. **怎么优化**这些端到端系统（训练目标/方法学）；
2. **怎么纳入安全机制**（学习型黑箱控制器怎么保证不失稳）；
3. **怎么降低训练数据集的采集负担**（这是对我们最要命的一条，见 §6）。

## 5. 感知的现实（对接贴片课，互为表里）

力矩不能直接测，只能**估计**——传感输入决定估计上限。roadmap 主线 IMU 为主、可融合 EMG/鞋垫（我们 FSR 属于鞋垫一族）。关键争议「EMG 是否必要」：Scherpereel 2026 *IEEE TBME*（引文表收录，全文未获取——**结论细节待学，不冒充读过**）。

## 6. 对我们 P1 的坐标系（AI 判断，标待确认）

- 我们 FSR+IMU+编码器组合：编码器给外骨骼侧状态，IMU 给运动学，FSR 给接触/相位——**缺的直接就是「力矩」这一层的观测**（要么靠模型估计，要么加 EMG/超声贴片——正是贴片课的问题域）；
- 数据负担：个人项目没有采集车队。roadmap 把数据负担列为三大挑战之一，反过来问「数据能多小」是我们的现实问题（学习目标之一：学完给 P1 传感与控制选型一份有据判断——这正是本科开科验收判据）。

## 续讲（2026-10-07 会话，ch01 深水区）

> 用户三题自测后追问四轮，本节为讨论实录要点。标注：题录级=只核对过引文表未读正文；AI 判断=本会话推理。

### 1. 力矩为什么测不到：传感器只能测流经它自己力路的力

- 实验室金标准 = 测力台（6 分量 GRF：3 力+3 力矩）+ 动捕 + 环节参数表（Dempster/Winter，即 L1 第二章内容）→ 牛顿-欧拉逆动力学逐段递推。
- 可穿戴版每环退化：鞋垫只测法向压力（**剪切力与自由力矩是断链第一环**）；IMU 漂移；环节参数是尸体表近似。「可穿戴逆动力学」从第一天起就是近似器——task-agnostic 的学习模型就是把这个计算变成可学对象。
- **动力学传感器必须串在力路里承力**（应变片=承力弹性元件、测力环串传动轴、FSR 承体重）；运动学传感器（编码器/IMU/摄像头）是旁观者。类比 L3「观察不扰回路」：力传感器是电流表（串联参与），不是电压表（并联旁观）。生物力矩的力路在肌腱内，解剖学没留接口——不可测是结构性的。
- 可测的近亲：**人机交互力矩**（设备侧力矩传感器测总力矩 − 电机已知力矩 ≈ 生物力矩），限制=刚性传动/人体关节非理想铰/并联结构生物力矩不全走设备。Molinaro 2024 是否用此招未读不冒充。
- 力矩传感器三原理复习：应变片/惠斯通电桥；SEA 弹簧形变；电机电流×KT（moteus 即此路线，L3 目标）。

### 2. 传感器堆料为什么救不了：缺的不是输入是「带标签的训练对」

- 力矩是导出量，可穿戴传感器永远只给力矩的相关量；映射（相关量→力矩）只能从实验室标定的配对样本学。
- 加传感器=加输入维度不加标签 → 维度灾难/过拟合风险升。比喻：传感器是眼睛、算法是大脑、带标签数据是教材——眼睛变多教材不会变多。
- 自仓实证回环：T-039 四片 FSR 各有脾气、T-040 接反+循环论证——传感器数×个体差异标定成本。
- 步态力矩其实高度有模式（准周期，自证=左跟低点领先左跖 100–400ms，10-06 实测）；难在活动切换瞬间与个体间差异（域适应文献砍的是后者）。

### 3. EMG：好闹钟，坏尺子

- 领先性真（电-机械延迟，文献量级几十毫秒，AI 设定待确认）——解决 when 不解决 how much。
- 幅度映射本身是时变函数（长度-张力/速度-张力/疲劳/电极位置/串扰）；髋项目尤其致命：髋屈主力髂腰肌是深肌，sEMG 够不着。
- 「EMG 是否必要」= Schonhaut 2026 TBME 未决争议（题录级）——争议存在本身说明 IMU 估计器的力矩幅度精度可能已追平。

### 4. 用户原创综合：绝对映射非必需，人响应可当弱标签（素材 T-045）

- 用户想法：人不抵抗/主动卸力=助力方向对，抵抗/加力=方向错——以此纠错。
- 对应真实路线A：HIL 优化（Zhang 2017）拿人当目标函数（代谢面罩），代价=慢（分钟级滞后）/每任务一调（task-specific 病根）/只出低维曲线。
- 对应路线B：交互力/EMG 变化当奖励，秒级响应（AI 判断+题录级方向）。
- 深一层：人响应本身是生物力矩的**弱标签**（助力使 EMG 降=方向对齐生物力矩）→ 配方「预训练（公共数据/仿真）+ 域适应 + 人响应在线校准（后训练）」。助力=k×估计力矩，形状对+增益用人反馈校准即可，绝对牛·米并非代谢最优的必要条件（AI 判断，待确认）。
