## 已学概念

### tendon 两类：fixed vs spatial

- fixed = 关节位置的**线性组合**（代数式），无几何形状；spatial = site 指定路径的真三维绳（可绕滑轮、可视化，数值更难调）。
- 两个正交维度：**绳长怎么算**（fixed/spatial）× **绳什么材质**（刚体索 / 弹簧——tendon 自带 stiffness/damping 属性）。
- 用户曾误解「绳长不变 ⇒ 张力恒定」，已纠正：张力是求解器解出来的结果（执行器施加多大的力，绳就多紧），与绳长是否守恒无关。

### coef 的物理意义

- 用户自己推导得出：绳长变化 = 半径 × 转角（弧长公式），故 coef 数值 = 绕绳滑轮半径（米）。引擎只当线性系数算，物理意义是人赋予的。
- 传动比从半径比里长出来：4.5:1 = 0.0585/0.013，不显式写在任何地方。

### 执行器绑 tendon 后单位变化

- `joint="ankle"` → ctrl 是力矩（N·m）；`tendon="bowden"` → ctrl 是**张力（N）**。
- 核心换算：踝上力矩 = 张力 × 滑轮半径。

## ✅ 审查题（09-12 出题 → 09-16 用户作答，通过）

> 12.0 N 档：踝执行力矩 0.70 > 重力矩 0.59，净力矩向下，脚为何停在 -45.9° 不继续转？

- 用户独立完成：弧度换算对位（-45.9° = -0.8 rad 正中 range 下限；5N 档 +34.4° = +0.6 rad 上限）+ 点名 radian 单位陷阱（忘写 compiler angle=radian 本题答案直接改写）。
- 判卷纠错两处：① tendon 张力双重记账（张力×半径已是 qfrc_actuator，同一份力不能既驱动又阻止）；② coef 误记为关节角度（实为滑轮半径，L = coef×θ，09-12 用户自推过的弧长公式）。
- 机制收尾（判卷补全）：撞限位即挂 efc 约束（第二章 type-3 那类），求解器生成恰好抵消净力矩的 qfrc_constraint——门抵门框，你推多狠门框顶多狠。停在哪由 range 定（位置边界），门框受多大压由张力定。
- 实证（tendon_qfrc_check.py，四路记账+平账校验）：10.1N 自由平衡 constraint=0.000；12N constraint=+0.106（≈手算 0.11）；15N 同角度 −45.9° constraint=+0.282；5N 上限镜像 constraint=−0.039；平账校验全 ≈0。符号坑：物理重力矩 = −qfrc_bias（MuJoCo 把重力放等式左边）。

### 沉淀概念：关节限位 = 约束力

- range 是位置边界非力边界：越界尝试被求解器用约束力顶回，静止时约束力 = 净力矩。
- 停转三角：执行（−0.70）+ 重力（+0.60）+ 约束（+0.11）= 0——四路记账里最后一路就是它。
