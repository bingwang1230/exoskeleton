# 隔离体图（FBD）：画谁、切哪、标什么

## 概念定义

FBD（Free Body Diagram，自由体图）= 力学版的系统边界分析：选定研究物体，把它从世界里「切」出来，其余世界对它的一切作用只用力/力矩箭头表示。画法三问：画谁（含未知量且受力最简的物体）、切哪（关节/支座/接触面）、标什么（每刀处标对方施加的力：作用点+方向；纯力矩用弧形箭头）。铁规则：边界之内不画内力（体内成对内力互相抵消）。重力是全身体积力，其合力作用点=质心（这不是约定，是定理）；摩擦方向由「有无滑动趋势」判定，静止且无水平趋势时 f=0。

## 学习过程

@2026-09-05
- **初始理解**：用户一眼认出这就是中学的受力分析——正确，FBD 是它的工程纪律版：切法自选 + 刚体引入纯力矩（中学质点模型只画力）。
- **误解与纠正**：重力作用点最初想画在脚上 → 追问后自己猜到「质心」并追问为什么。讲解：重力是作用在每个质点上的无数平行力的合力，可以证明其总效果=总重量作用于质心一点（对任意点取矩等效）——作用点只有在讨论旋转/力矩时才有物理后果，质点模型把它藏掉了。用户随即自己点破「研究旋转和力矩么」——命中要害。
- **关键讨论**：①静摩擦=0 的判定：无水平受力→无滑动趋势→f=0；静摩擦是「按需配平」的反作用力（上限 μN）；②求髋力矩必须换刀法：整个人隔离体中髋是内力不显现 → 在髋处切成上半身/下半身两个隔离体，切口处各出现一个力+一个力矩，且成对（F′=−F，M′=−M，牛顿第三定律）——用户独立推出，包括「切口处应出现力矩」。

## 关键洞察

- 用户原话：「髋关节对于整个人来说属于内力」——一次到位；「把上半身和下半身用髋关节相连画两个体块……应该出现一个力矩」——独立预判了切口的力+力矩结构。
- 平衡的另一面：N 与 f 的合力必须恰好竖直、与 W 共线过接触点（站坡上不滑不转的全部秘密）。
