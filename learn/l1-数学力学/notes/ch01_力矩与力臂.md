# 力矩与力臂（平面问题化简：叉乘→带符号标量）

## 概念定义

力矩 = 力 × 力臂，力臂 = **转轴到力作用线的垂直距离**（不是到作用点的距离）。平面问题中叉乘退化为带符号标量：M = x·Fy − y·Fx（原点=转轴，逆时针为正）。分量视角：竖直分力 Fy 的力臂 = P 的横坐标 x；水平分力 Fx 的力臂 = 纵坐标 y——「找垂线」变「代坐标」。取矩点技巧：ΣM=0 对任意点成立，专挑未知力作用线穿过的点取矩，让未知量从方程消失。

## 学习过程

- **初始理解**：纯文字讲解（含叉乘式）没看懂 → 配图三张（推门直觉 / 分量-力臂对应 / 按真实比例的题目图）后进入计算。教训：几何概念必须配图教。
- **裸重演**（独立计算）：题1 M = 400×0.05 = 20 N·m ✓，力臂取 0.05（垂直距离）而非 0.112——正确；方向表述为「往前仰」（词序混杂，前倾意图为主，待确认）。题2「没有取垂线」一句话正中要害 ✓。题3 先说「重力力臂是 0？」（正确！）随即自我否定「不对」，最终答「需要知道髋抗旋的拉力」——结论正确（对质心取矩会让髋关节力 F 进入方程），但过程有个自我怀疑的晃动，反映对「力矩对参考点的依赖性」还不完全扎实。
- **客观裁判**（代码对拍）：M = 0.05×(−400) − 0.10×0 = **−20 N·m**（负=顺时针=前倾）；力臂式 |M| = 400×0.05 = 20 ✓；错误算法 400×0.1118 = 44.7 ✗。两法对拍一致，用户裸重演与裁判一致。
- **关键澄清**：①重力对质心的力臂确实为 0（用户第一直觉对，「不对」是过度修正）；②取矩点经济学——对髋取矩：丢掉未知 F、保住已知 W → 一击解出；对质心取矩：丢掉已知 W、换来未知 F → 亏本。

## 关键洞察

- 用户：「没有取垂线」——对错误算法的病理一句话定位（用点到点距离冒充垂直距离）。
- 代码对拍的意义现场演示：同一个力矩，叉乘式与力臂式两条路算出同一数字，错误算法立刻现形。
