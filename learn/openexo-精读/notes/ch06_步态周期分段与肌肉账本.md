# 步态周期分段与髋踝肌肉账本（第六章前置坐标系）

## 概念定义

**周期定义**：一只脚连续两次跟击之间。快走 ~0.8s、慢走 ~1.4s。0% = 该脚跟击瞬间（时刻+刻度零点）；100% = 下一次同脚跟击（曲线首尾相接循环）；中间 % = 归一化时间。定位锚：对侧脚跟击在 ~50%，同侧 toe-off 在 ~60%。

**分段走读表**（右脚）：

| 相位 | 身体 | 肌肉 | 髋外骨骼 |
|---|---|---|---|
| 0–10% loading | 体重砸上，微弯吸冲 | 髋伸肌离心刹车；踝跖肌离心（跟腱弹簧拉长） | 0 |
| 15–40% 支撑中后 | 滚过脚上方→蹬伸 | 髋伸向心：**臀大肌/腘绳肌** | 伸峰 ~5.5 Nm |
| 40–60% | 蹬离，跟抬起 | **小腿三头肌（腓肠肌+比目鱼）**向心蹬地=踝账 | 0（踝 PJMC 主场） |
| 60% toe-off | 腾空进摆动 | — | 0 |
| 60–84% 摆动前中 | 腿自己前摆 | 髋屈：**髂腰肌/股直肌** | 0（长零段） |
| 84–100% 摆动末 | 摆到身前减速准备落地 | 髋屈收尾、髋伸预备刹车 | 屈峰：84% 升→~92% 峰→100% 归零 |
| 100% | 再落地=新周期 | — | 必须 0（接缝） |

**两本肌肉账本别混**：
- **髋账本**：伸=臀大肌/腘绳肌（stance 推蹬）；屈=髂腰肌/股直肌（摆动）
- **踝账本**：跖屈=腓肠肌/比目鱼（蹬地，PJMC 主对象，28 Nm ≈25–30% 助力）；背屈=胫骨前肌（摆动勾脚防拖地，PJMC 摆动相恒定背屈力矩模仿对象）
- 「拉长→等长→收缩」循环（用户直觉，正确）= 跟腱弹簧（第一章）：踝背屈拉长储能→跖屈收缩释放——发生在踝不在髋

**助力量级两本账**：髋 5/5.5 Nm ≈ 生理峰（~40–70 Nm，AI 补待确认）**~10%**（搭把手定位）；踝 28 Nm ≈ **~25–30%**（跖屈蹬地=耗能大头，代谢收益主场）。用户问「不是 30% 么」= 记的是踝的账。

**诚实标注**：84–100% 窗口的生理代价——髋屈肌峰发力在 initial swing（60–73%），OpenExo 压到摆动末段 = 不帮「启动摆动」只帮「收尾摆到位」，是「起点移 84% 避免不连续」的直接代价；Bryan/Franks 原曲线待查。

## 关键洞察（金句）

- 0% 和 100% 是同一个物理事件：曲线首尾相接转圈，接缝两端必须都是零
- 髋账本（臀/腘绳 vs 髂腰/股直）和踝账本（小腿三头 vs 胫骨前肌）是两本账，别混
- 助力不是全程护航：零段（吸冲期/摆动前中）和峰段一样是设计
- 髋 ~10% 搭把手，踝 ~25–30% 主力——按代谢收益分配火力
