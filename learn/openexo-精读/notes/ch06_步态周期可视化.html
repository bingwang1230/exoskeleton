周期内相位右脚 / 身体在干嘛出力的肌肉髋外骨骼给多少
0–10% 落地吸收 体重砸上来，腿微弯吸收冲击（loading response） 髋伸肌群离心刹车；踝跖肌群离心——跟腱弹簧被拉长（踝的账） 0（冲击吸收期助力反而碍事）
~15–40% 蹬伸 身体滚过右脚上方 → 蹬直腿向前推 髋伸肌群向心：臀大肌、腘绳肌 伸助力峰 ~5.5 Nm（≈生理髋峰的 ~10%）
40–60% 蹬离 脚跟抬起 → 脚趾离地 腓肠肌+比目鱼向心蹬地——踝的账 0 —— 踝外骨骼（PJMC，28 Nm）主场
60% 脚趾离地 右腿腾空，进入摆动相 —0
60–84% 摆动前中 右腿自己往前摆 髋屈肌群向心：髂腰肌、股直肌 0（生理屈肌发力主要在此，OpenExo 不在这里助力）
84–100% 摆动末段 腿摆到身前、减速、准备落地 髋屈肌收尾；髋伸肌预备刹车 屈助力：84% 出发 → ~92% 峰 → 100% 归零（跟击前必须结清）

两本肌肉账本，别混

髋账本（本页主角）

伸（stance 蹬伸）= 臀大肌、腘绳肌 ↔ 伸助力 5.5 Nm
屈（摆动收腿）= 髂腰肌、股直肌 ↔ 屈助力 5.0 Nm

踝账本（下一概念 PJMC 的主角）

跖屈（蹬地）= 腓肠肌、比目鱼 ↔ 28 Nm ≈ 生理峰的 25–30%
背屈（勾脚防拖地）= 胫骨前肌 ↔ 摆动相恒定背屈力矩的对象
「拉长→收缩」循环 = 跟腱弹簧，在踝不在髋。
量级对账：你记的「30%」是踝的账（28 Nm ≈ 生理踝峰 ~100+ Nm 的 25–30%，代谢收益主场）；髋只有 ~10%——搭把手定位。生理峰值为 AI 补常识，待确认。

84–100% 窗口的生理代价（诚实标注）

生理髋屈肌峰发力在 initial swing（60–73%）；OpenExo 把屈助力压到摆动末段（84–100%）——不帮「启动摆动」、只帮「收尾摆到位」，这是「起点移 84% 避免跟击不连续」的直接代价。图中紫色肌肉条与紫色助力曲线的错位即此事。原方案（Bryan/Franks）曲线待查原文。
检验题：左脚的屈峰，出现在右脚周期的哪个 % 附近？

左脚相位 = 右脚相位 − 50。左脚屈峰在左脚相位 92% → 换算到右脚周期：(92+50) mod 100 = ~42%。图上虚线浅紫的峰就落在 42% / 142% / 242%——hover 验证。
