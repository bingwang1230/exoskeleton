坐标：一只脚（右脚 R）连续两次跟落地 = 一个周期。0% = 右脚跟击瞬间，100% = 下一次右脚跟击（曲线首尾相接转圈）。中间的 % = 从这次跟击起过了周期长度的百分之几。左脚（L）比右脚晚半个周期（L 的跟击发生在 R 的 50% 处）。

相位段右脚 / 身体在干嘛出力的肌肉髋外骨骼给多少
0–10% 落地吸收 体重砸上来，腿微弯吸收冲击（loading response） 髋伸肌群离心刹车；踝跖肌群离心——跟腱弹簧被拉长（第一章的账，踝） 0（冲击吸收期助力反而碍事）
~15–40% 蹬伸 身体滚过右脚上方 → 蹬直腿向前推 髋伸肌群向心：臀大肌、腘绳肌（「后腿蹬直」的髋部分） 伸助力峰 ~5.5 Nm（≈生理髋峰的 ~10%）
40–60% 蹬离 脚跟抬起 → 脚趾离地 腓肠肌+比目鱼向心蹬地——这是踝的账，与髋无关 0 —— 这是踝外骨骼（PJMC，28 Nm）的主场
60% 脚趾离地 右腿腾空，进入摆动相 —0
60–84% 摆动前中 右腿自己往前摆（过身体下方→甩到身前） 髋屈肌群向心：髂腰肌、股直肌 0（很长的一段零——生理屈肌发力主要在此，但 OpenExo 不在这里助力）
84–100% 摆动末段 腿摆到身前、减速、准备落地 髋屈肌收尾；髋伸肌预备刹车 屈助力：84% 出发 → ~92% 峰 → 100% 归零（必须在跟击前结清，否则相位归零瞬间力矩跳变）
100% = 0% 右脚跟再落地 = 新周期开始 — 接缝两端都必须是 0

两本肌肉账本，别混

髋账本（本页主角）

伸（stance 蹬伸）= 臀大肌、腘绳肌 ↔ 伸助力 5.5 Nm
屈（摆动收腿）= 髂腰肌、股直肌 ↔ 屈助力 5.0 Nm
外骨骼 = 同轴电机顶到大腿箍，力矩直接作用在髋。

踝账本（下一个概念 PJMC 的主角）

跖屈（蹬地）= 腓肠肌、比目鱼 ↔ PJMC 主对象，28 Nm ≈ 生理峰的 25–30%
背屈（勾脚防拖地）= 胫骨前肌 ↔ PJMC 摆动相恒定背屈力矩的模仿对象
「拉长→等长→收缩」循环 = 跟腱弹簧，发生在踝不在髋。
助力量级对账：你记的「30%」是踝的账（28 Nm ≈ 生理踝峰 ~100+ Nm 的 25–30%）——跖屈蹬地是行走耗能大头，代谢收益主场，火力足；髋只有 ~10%（5.5/5.0 Nm ≈ 生理髋峰 ~40–70 Nm 的零头）——搭把手定位。生理峰值数值为 AI 补的常识，待确认。

84–100% 这个窗口的生理代价（诚实标注）

生理上髋屈肌峰发力在 initial swing（60–73%）——把腿从身后拉起来最费劲的时刻。OpenExo 把屈助力压到摆动末段（84–100%），等于不帮「启动摆动」、只帮「收尾摆到位」——这是「起点移至 84% 以避免跟击不连续」的直接代价。原方案（Bryan/Franks）曲线形状待查原文。下图中紫色肌肉条（生理激活）与紫色助力曲线（OpenExo 助力窗）的错位就是这件事。
检验题：左脚的髋外骨骼，在右脚周期的哪个 % 附近给出屈峰？

左脚相位 = 右脚相位 − 50（晚半个周期）。左脚自己的屈峰在左脚相位 92% → 换算到右脚周期：(92 + 50) mod 100 = ~42%（图上紫色虚线峰的位置，你 hover 到那里看得到）。若问的是出发（84%）：(84+50) mod 100 = 34%。看虚线验证你的答案。
