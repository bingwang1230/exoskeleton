# 腰带平台与快换组合 + 髋直驱构型

## 概念定义

**模块化哲学四层化身**(第二章三件套+机械层):软件类层级/SD 配置/CAN+8-pin/**M5 孔阵**——金句:**机械层的 SD 卡叫孔阵**;SD 卡吸收软件差异,孔阵吸收骨骼差异。

**腰带平台**(母舰):
- Osprey IsoForm4 登山腰带(4 尺码)——买的不是造的:**重物压髂骨**(骨盆天然承重货架,力走骨骼不走肌肉),登山界几十年人体工学的成熟答案;真实基线的又一次胜利
- 电子/电池仓 3D 打印挂载、**居中**(左右对称=转身转动惯量最小;腰上便宜≠腰上免费,腰上还要居中)
- 电池 22.2V 1800mAh≈40Wh(T-013 充电宝天花板)
- M5 孔阵安装板:模块上下前后滑动找位适配解剖差异(髋宽/腿长/腰围)

**髋直驱链条走读**:
```
腰带→M5孔阵板→铝 外展/内收铰链→碳纤支架→AK60-6→碳纤直立杆→大腿箍(多尺寸/衬垫/可调带)
```
2.9 kg、BOM $2,000–2,500。

- **★外展/内收铰链=自由度管理**:矢状面(侧视图平面,屈/伸)传力助力;外展/内收(面外动作)用铰链**放生**。人不是单平面机器人,每步骨盆都有面外运动;**只锁一个轴、其余轴礼貌放生——传力的轴对齐,不传力的轴放开**。锁多了=绑架人体,锁少了=助力漏掉。
- **开环是直驱挣来的特权**:直驱刚性链+电机内置编码器/电流环(AK 自己闭环,只是不知道「腿」),指令无损耗环节可骗→系统层免传感器。踝四道传动(链轮→链条→钢缆→鲍登)每道有摩擦弹性→必须 inline 力矩传感器闭环。**闭环是传动的保险费**。

## 关键洞察(金句)

- 机械层的 SD 卡叫孔阵(模块化四层化身收齐)
- 重物压髂骨:骨盆是天然承重货架(登山界的血泪答案,买不是造)
- 只锁一个轴,其余轴礼貌放生——锁多了绑架人体,锁少了助力漏掉
- 删掉被设计的自由度,自然界还你一个不被设计的自由度(受控放生 vs 不受控放生)
- 计划外载荷总在全链最软的地方结算(软组织界面是隐形主线)
- 开环是直驱挣来的特权,闭环是传动的保险费
