# 七条设计目标及其取舍

## 概念定义

OpenExo 的七条设计目标不是并列清单：2/3/4/7 各盯一层（软/电/硬/控制），1 管场景（无缆），5 管新手复现，6 管生态（鲍登线作他人创新起点）。总纲：最少冗余、关节无上限、任何人任何场景可用。七条是第一章「四段壁垒」的设计学反转——壁垒在哪层，目标就立在哪层。每条都有代价，代价由物理写就：无缆 → 把能源背上身（40 Wh ≈ 充电宝，25 min）；鲍登 → 摩擦+柔性 → 必须闭环+力矩传感器；远端轻 → 传动链复杂。

## 学习过程

@2026-08-31
- **初始理解**：猜模块化的代价是「接口简单→自由度减少」；猜「任何场景可用」的代价是可靠性冗余设计导致耗电大增。
- **误解与纠正**：
  1. 「冗余耗电」→ 无缆的代价是**能源税本身**（锂电池 ~0.25 kWh/kg 是物理账，删冗余省不出来）。用户当场吸收并反推：40 Wh ÷ 25 min ≈ 95 W 平均电耗 vs 机械功 10–20 W → 大头是损耗，「利用率提高则电池有很大优化空间」——独立命中论文结论「电池是第一瓶颈/改进首目标」。
  2. 「直驱省掉鲍登摩擦 → 电池利用率更高」→ 半对：省摩擦（10–30% 量级）但电机被迫直出 28 Nm（经 4.5:1 只需 6.2 Nm，恰为 AK80-9 连续额定），铜损 ∝ τ² → ~20×，净利用率大概率更差，除非电机加重 5 倍撞回远端质量税。**传动不只是搬质量，更是让小电机待在高效工作点；减速比不是损耗是套利。**
  3. 「直驱下漂移不能像髋一样推断」→ 表述反了：直驱 = 刚性 = 漂移可推断，担忧随之消失；鲍登漂移是「现设计为何必须闭环」的原因，非「为何不直驱」的原因。论文真正的第二条理由：最小化远端质量**与侧向突出**（穿鞋/绊脚/社交）。
- **关键讨论**：28 Nm→功率（P = τω，~56 W 峰值 / 10–20 W 平均）；28 Nm 体感锚（30% 体重 ≈ 280 N 压前脚掌）；踝低速高扭（~2 rad/s）vs 电机高速低扭 → 4.5:1 + 9:1 减速的意义；RMSE 定义（sklearn 同款）与「三关节都 ~7%」的深读——闭环的意义是让柔性传动**追平**刚性传动的裸机水平，不是数字更好看。
- **独立产出**：（概念型，讨论验证）能源账反推与直驱收益/代价权衡由用户自主完成；铜损 20× 一句话解释留作收口 verify。

## 关键洞察

- 设计目标是壁垒的镜像；每条目标的价格标签由物理写就（能源税/摩擦柔性税/质量税）。
- 「助力设备的能耗大头在损耗不在做功」——95 W 里做功仅 10–20 W（AI 反推估算，待验证）。
- 直驱 vs 传动的真权衡是三方不等价：远端质量税 vs 摩擦柔性税 vs 电机工作点，不可能全赢。
