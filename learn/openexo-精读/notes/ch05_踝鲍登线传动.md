# 踝鲍登线传动(3.9 kg 的传力长征)

## 概念定义

**总起(三笔账闭环)**:踝需求行走最大力矩(~100Nm 级)→要大电机→重→放腰上→力怎么到脚→鲍登线。3.9 kg 系统最重构型,复杂度全在输送。

**传力链走读**:
```
腰置 AK80-9(内 9:1 行星)
 ↓①26mm 定制链轮(把「转」变「拉」,τ=F·r 的杠杆旋转版)
 ↓②3D 打印套筒内链条(转→直线拉力;套筒罩住=安全+导链)
 ↓③铝接口→钢缆(链条擅传力,钢缆擅拐弯)
 ↓④鲍登护套下行(张力走钢丝,压力走护套)
 ↓⑤踝滑轮(4.5:1=半径比:13mm×4.5≈58.5mm≈乒乓球直径,AI 推算)
 ↓⑥碳纤足板插鞋+小腿箍(力矩两落脚点;外骨骼传力从人体来回人体)
```

**关键账**:
- **钢缆张力**=媒婆:F=τ_m/r_sprocket=18Nm/0.013m≈**1385N 峰值**(毫米级钢缆扛 140kg;1.5mm 级破断~2500N 训练数据,安全系数~2——**P1 安全件,断缆回弹必须机械限位不靠软件**)
- **踝滑轮身兼三职**:①减速器(半径比)②换向器(直线→绕踝轴转动)③**踝关节本体**(外骨骼的「踝」=滑轮转轴;同轴挂全部踝部传感器——动力+信息枢纽)
- **同轴对齐**:机构自己的铰链(小腿箍→滑轮轴→碳板)悬在踝旁不贴骨;对准解剖标志(内外踝尖连线中点),靠箍的高度/前后可调;**轴偏几毫米=每步界面剪力(计划外载荷在最软处结算:脚背/鞋面)**
- **护套**:可弯不可压(轴向抗压+弯曲柔性);**张力走钢丝,压力走护套——一对分工的力偶**;摩擦是要消灭的损耗不是传力机制(capstan 回勾,直线度=生命线)
- **TPU+onyx 应力释放**:护套出口高应变点(反复弯折),TPU 渐变让弯折受控——「要么安排它去哪,要么它自己找地方弯」机械层兑现;onyx 刚性件/TPU 柔性缓冲,3D 打印两种材料一个人不开模——「AI 时代一人造外骨骼」的物理基础
- **传感器语义**:inline 力矩传感器测**外骨骼真实输出**;生物力矩测不到(藏肌腱里),只能 FSR 回归**估计**——金句:**PJMC 跟随的是「估计的你」,助力精度上限=回归方程精度**
- 设计目标:最小化远端质量(踝以下最贵地址)+侧向突出(两脚交叠踢腿);碳板插任意鞋=鞋版配置吸收实例间差异

## 关键洞察(金句)

- 钢缆是媒婆:电机力矩÷链轮半径=张力,踝端力矩=张力×滑轮半径
- 滑轮身兼三职:减速器/换向器/踝关节本体——踝部传感器全住这根轴
- 张力走钢丝,压力走护套;摩擦是敌人不是媒人
- PJMC 跟随「估计的你」——助力精度上限=估计精度
- 链轮换大=账本搬家:买走钢缆余量与背驱,支付电机力矩上限与 4× 铜损;稀缺账本不能欠债
- τ=F·r 是扳手:轮子就是焊在轴上的扳手
