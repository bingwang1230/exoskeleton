# 双 MCU 分工(Teensy 4.1 控制 / Nano BLE 33 通信)

## 概念定义

```
你的手机/笔记本(跑 App:看曲线、调参数)
   ‖ 无线·蓝牙 BLE
Arduino Nano BLE 33 【慢芯片·通信官】(nRF52840, 64MHz M4)
   ‖ 两根线·UART(独木桥)
Teensy 4.1 【快芯片·指挥官】(600MHz M7)—— SD 卡(开机读配置)
   ‖ CAN 总线
CubeMars AK 电机 ×最多4颗(每颗内置自己的 MCU)
   ← ADC 引脚 ← 传感器(力矩/角度/FSR)
```

- **Teensy 4.1**:数据采集(ADC)、控制计算、执行器通信(CAN)——快时钟+好 ADC,但没有蓝牙。
- **Nano BLE 33**:只管 BLE 连伴随 App——有蓝牙但慢一个数量级,别的都弱。
- 两颗之间 UART 相连;软件上**数据类(ExoData/SideData…)与计算类镜像分层,Nano 只镜像数据类**——Nano 是数据的搬运工(打包↔App),计算逻辑只在 Teensy。
- **四级芯片联邦**:App 设备 → Nano → Teensy → 电机内置 MCU,每级只和邻居说话。

## 学习过程

@2026-09-03~04(9-04 补录,违反随学随记纪律,用户发现笔记停在 9-2 后补)

- **黑话从零建画面**(用户自陈「很多都不行的」,降速处理):MCU=单芯片小电脑;开发板=MCU+USB+插针的现成小板(Teensy/Nano 都是采购的,自研只有第四章那块 PCB);Nano 不是纳米,是 Arduino 产品线名(板子小);烧录=语言化石(曾祖父 PROM 靠烧熔丝、真的只能写一次;现在 Flash 电擦除可反复,「烧」只是词没死);UART=两块板间两根线的电话线;CAN=两股辫子上的广播局域网(不是主板!)。
- **分工动机的连环四猜**:用户猜「并行加速?冗余备份?」→ 均判 ✗(并行是顺带效应;两颗无互备关系,一颗坏另一颗救不了场);「通信不阻塞控制」✓。锐化为:**通信是不确定的,控制是死节的;把不确定的东西隔离在另一颗芯片,是最笨也最硬的实时保证**。Arduino 裸机 loop() 无抢占调度,BLE 栈阻塞式占用 CPU 的时机不可控;分两颗=用硬件边界做时间隔离。另一条路是 RTOS(截止时间必达的抢占调度),他们没选,符合「非电子专家也能搞」哲学。
- **Exo→Side→Joint 辨析**:Joint 是**外骨骼自己的机械关节**(踝构型=滑轮+碳板那套),不是人体组织;设计上其转动轴要对准人关节轴(错位大力传歪)。树=换构型不改代码(左边挂髋右边挂踝,树还是那棵树)。
- **UART 交叉线用户自答✓**(板1 TX→板2 RX 交叉);追问「同时发冲突吗」→ 引出全双工(收发独立通道,永不冲突)+ UART 真坑在异步无时钟(须先约波特率,差几个百分点=乱码)。「同时发会撞」只在共享介质时存在 → 自然过渡到 CAN 仲裁(ID 逐位比拼,优先级高者赢)。
- **ADC 线性度追问**(用户复述 ADC 定义近乎逐字准确,追问「格子凭什么均匀——有机制保证还是靠线性拟合?」):SAR 型=内部 DAC+比较器二分猜电压;格子均匀性靠**同一块硅上电阻/电容做得一样大**(半导体工艺,硬件保证非软件拟合)。不完美处有名字:失调(平移)/增益误差(斜率)/INL(弯)/温漂;校准只能修整体歪斜,修不了个别格子忽宽忽窄。**工程真相:ADC 非线性是误差预算最小项,大头在传感器本身**(FSR 高度非线性)——论文「穿戴后量程式校准」补偿的是传感器+装配+人体系统误差,不是救 ADC。类比:印刷刻度的尺子 vs 你量的东西本身歪得多。
- **CAN vs UART 本质三区别**(用户问「只是多对多 vs 单对单么?」):拓扑之外还有——①信号:UART 单端(一根线对地)vs CAN 差分(H/L 互为参照,共模噪声相减抵消)②可靠性:UART 裸奔无重传 vs CAN 有 CRC+ACK+自动重发+坏节点隔离③寻址:UART 无地址 vs CAN 报文带 ID 广播过滤。出生环境决定:CAN 生在汽车引擎舱电磁地狱,所以长了这两个器官;UART 在裤腰内侧环境温和就够用。**布线纪律预记:UART 线绕过电机驱动器=乱码时间问题**(硬件章再遇)。

## 关键洞察(金句)

- **通信是不确定的,控制是死节的——把不确定的东西隔离在另一颗芯片,是最笨也最硬的实时保证**(硬件边界做软件做不到的时间隔离)
- UART 是电话线,CAN 是车间广播系统;CAN 比 UART 多活的两个器官=差分(抗噪)+校验重发(可靠),都长在汽车电磁地狱的出生证上
- 四级芯片联邦,每级只和邻居说话
- ADC 线性靠工艺(同硅匹配),校准修传感器系统误差;ADC 非线性是误差预算最小项
- 全双工无冲突概念,冲突只存在于共享介质(仲裁是 CAN 的税)

## 误解与纠正记录

| 原表述 | 判定/纠正 |
|---|---|
| 「是并行加速吗?」 | ✗ 顺带效应,计算量一颗绰绰有余 |
| 「是冗余,一颗坏了另一颗还能用?」 | ✗ 无互备关系,是分工不是备份(Nano 坏蓝牙断,Teensy 坏控制瘫) |
| 「CAN 是类似主板的东西,芯片放在上面?」 | ✗ 主板=安装互联的物理基座;CAN=两根线+一套说话规则(广播总线) |
| 「烧录是只能写一次?」 | 半对:PROM 曾祖父代真的烧熔丝一次性;现在 Flash 可反复,词是化石 |
| 「ADC 是传感器入口的插槽?」 | ✗ 是芯片内部电路模块;引脚只是通往它的窗口 |
