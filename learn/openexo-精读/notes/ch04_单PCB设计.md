# 单 PCB 设计(4 电机/双侧 2 关节/8-pin 传感扩展)

## 概念定义

**PCB**(印刷电路板):元器件焊在板上、连线是蚀刻铜箔——取代面包板(拔插方便但会松)。原理图→布局布线→打样,样板几十至几百元/一周(复现时要走一遍)。

OpenExo 这块板的四个角色:

```
电池 22.2V → ①配电盘(分发给最多 4 颗 AK 电机)
             ②CAN 枢纽(4 电机总线汇聚,Teensy 一条走线上总线)
             ③传感插口(每侧 8-pin 座,传感器乡下进城口)
             ④母板(Teensy/Nano 插在板上,像主板插显卡)
```

**单块哲学(vs FlexSEA 多板互联)**:
- 可靠性账:板间连接器=可松动的故障点;一块板内部全焊死铜走线——**装配时的复杂度搬进设计时一次性付清**
- 人群账:「非电子专家也能制作」=第一章电壁垒的兑现场,墙被预制成了板
- 代价:不灵活,改=重画板重打样(**抽象税的电子版**:慢车道从改代码变成改板)

**插拔哲学(Teensy/Nano 插而不焊)**:
- 过时速率错位:PCB 慢车道(定制+验证),开发板快车道(通用商品隔天到货);**快过时的件可插,慢过时的件焊死,每层按自己速率演化**——「接口吸收速率差」第三次出现(换电机不动架构/换构型不改代码/换板不换开发板)
- 坏的经济账:USB 口是 Teensy 最易坏件;可插让最易坏=最易换;焊死则一颗几十美元芯片拖整块定制板下水
- 代价的讽刺:**插座本身就是故障点**——可插的可靠性代价恰是那个插座
- 焊死的优势(用户 Mac 例):省空间+连接可靠+批量成本低——消费产品(Mac)选焊死,研发平台(OpenExo)选可插:**同一问题不同优先级不同答案**

- AI 错字事故:「8-pin 排线座」误输出「庥」,当场认错(诚实第一)。

## 关键洞察(金句)

- 把装配时的复杂度搬进设计时一次性付清
- **快过时的件可插,慢过时的件焊死——每层按自己的速率演化**
- 可插的可靠性代价恰是插座本身(没有免费午餐,只有优先级)
- 消费产品焊死、研发平台可插——同一问题不同优先级不同答案
