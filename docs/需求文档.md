# 外骨骼计划需求文档

> 立项：2026-08-27 kickoff（决策见 docs/决策记录.md）｜章程整理：2026-08-29（同日随总部拆入独立仓库）
> 本档是项目章程：定义、交付物、边界、约束、风险。三线怎么做见 docs/三线计划.md，做到哪了见 PROGRESS.md。

## 1. 一句话定义

**一个以「AI 时代，一个人就能搞外骨骼」为主叙事的个人事业项目**：在 10 小时/周的人时预算内，用 12 个月把论文里的助力外骨骼真的造出来、穿上、量出数据，并把全过程公开成档案与内容。

先挑明一个隐含假设（这是本项目与普通内容项目的分界线）：**项目首先为用户自己而做**——能力建设与作品集是第一交付物，公众叙事是它的副产品。受众按优先级：maker/同行社群 ＞ 招聘方与合作方 ＞ 关注养老与老龄化的公众。

## 2. 交付物与验收标准（12 个月）

| # | 交付物 | 验收标准（=阶段判据） | 三线归属 |
|---|---|---|---|
| 1 | 单关节（踝）外骨骼实物 | 在人腿上可控输出力矩（Phase 2 判据） | 做 |
| 2 | 实测数据 + 实验报告（n≥3） | 方法/数据/报告全公开可复核，PDF 可下载（Phase 3 判据） | 做 |
| 3 | 个人网站（档案库 + 名片） | 可访问，含项目页/时间线/复盘（Phase 0 起） | 发·子产品 |
| 4 | 内容矩阵 | 小红书 1–2 篇/周；B站双周成片；YouTube 同源英文轨 | 发 |
| 5 | 隐性交付物：L1–L6 能力栈 + 作品集 | 作品集页挂「求职/合作」入口（Phase 4） | 学 |

网站是本计划中唯一确定的「产品」，Phase 0 立项时走完整产品开发流程（方法论库在 pebble_space `skills/产品开发/`），独立建仓，链接登记进 PROGRESS.md 卫星索引。

## 3. 不做清单（与「做」清单同等重要）

- **不做医疗宣称**：不宣称疗效、康复、防跌倒、适合老人使用（词库纪律，三线计划 §1.3）。依据：消费级助力外骨骼的有效性边界未被证明（20260825 调研报告 §2.2/§6）。
- **不做高风险人群实验**：骨质疏松、失能、高龄人群的任何可能致摔实验（三线计划 §7 红线）。
- **不做产品化销售**：不量产、不售卖、不做消费级适配；商业动作（众筹/咨询/开源赞助）Phase 4 视情况再议。
- **不做适老特化硬件**：P3（坐站/助起）在 Phase 3 判据通过前不立项。
- **不扩团队**：单人 + AI 是约束也是叙事本身，不做多人协作假设。
- **不开时政议题**。

## 4. 非功能性需求（约束）

| 维度 | 约束 |
|---|---|
| 人时 | 10h/周，只约束「人必须在场」的事；AI 时间不计入（防过载，不卡进度） |
| 安全 | 三线计划 §7 红线，不可妥协：假人盲测先行、急停硬接线、电池防爆、高风险人群排除 |
| 诚信 | 每个数字带出处（自测给协议、引用给链接）；AI 生成部分显式标注；失败不掩盖 |
| 资金 | 上限未定，Phase 2 询价后再做 P1 采购决策 |
| 平台风险 | 核心数据与内容始终有网站档案副本，对冲单平台风险 |

## 5. 最大风险（按杀伤力排序）

1. **工程线卡死、内容线空转（人设破产）**：叙事价值在「造出来了」这个事实。若数月无实物产出，三线滑向「聊外骨骼的博主」，与测评号无法区分。护栏：阶段判据门——工程判据（力控、实物、实测）是硬门，内容产出不构成跳门理由。
2. **安全事故**：真人穿戴实验致伤。护栏：§7（假人先行、硬线急停、高风险人群排除）。
3. **时间预算失守**：内容更新压力吞噬动手时间。护栏：预算只算在场时间 + AI 承担批量工作 + 每周一行周记暴露漂移。
4. **表达合规事故**：平台或监管对医疗暗示词汇的处罚。护栏：词库纪律覆盖标题/口播/营销语境。
5. **弃坑**：单人长跑项目的默认结局。护栏：公开承诺（起手帖）+ 双周可见产出 + 复盘规则（连续两月判据未过 → 重估范围，而不是硬撑）。
