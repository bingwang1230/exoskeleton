## 2026-09-02（第十四决策）volume 同步频率：周日 → 每日（本仓与 pebble 两仓）

1. **用户拍板，采纳**（基于当日评估）：exoskeleton（03:40）与 pebble_space（03:15）两个 volume_sync launchd 任务由每周日改为每日，时段不变（错峰保留）。评估实测：单次运行 exo ~0.15s / pebble 秒级、稳态零传输、复验 snapshot 只 stat 元数据——直接代价≈0；实质代价为 `--delete` 误删宽限期由最长 7 天缩至 1 天（子目录级归档语义不变），已知悉接受。

3. **落地**：两仓 plist 删 `Weekday` 键（StartCalendarInterval 只留 Hour/Minute 即每日）并重载；脚本文件名 `sync-weekly.sh` 沿用不改（历史可追，注释与 README 已注明）；pebble 侧 MySQL 周备份（周日 03:00）链条不变，其 dump 当日即随每日同步上盘。AGENTS §2/§10、PROGRESS 快照、两仓 volume_sync README 同步更新。
4. **首验（launchd kickstart 实跑）**：两任务 exit 0；pebble 积压 37 项（jam/ 1.4G 首次声明 owner=mac-mini）随首跑上盘，ext2 盘面核对一致。
