## 1. 叙事与词库纪律

### 1.1 人设一句话

不是测评者，不是厂商，是**造物者**：一个人 + AI，把论文里的外骨骼真的造出来、穿上、量出数据。故事的价值在"造出来了"这个事实本身，不需要证明产品对任何人有效。

### 1.2 为什么是外骨骼（内容的"为什么"层）

面向老龄化社会、让老人有尊严地自主起居——这个愿景只作为"我为什么选外骨骼"的动机叙事出现（第 1 条视频讲清楚，之后不反复贩卖），不进入任何具体产品的效用声明。

### 1.3 词库纪律【硬规则】

| 禁用（标题/口播/营销语境） | 替代 |
|---|---|
| 疗效、康复、防跌倒、医疗 | 造、复现、穿戴、试 |
| 助力、省力 XX%（作宣传语时） | "实测数据"（只在给出测量方法时使用） |
| 测评、评测、开箱（作内容定位时） | 复现记录、工程过程、从零造 |
| 适合老人/推荐老人使用 | 不说（消费级产品边界未证明，见调研报告） |

技术语境（论文术语、代码注释、数据表格）不受此限——"助力力矩 assistive torque" 是术语，照用。

### 1.4 内容铁律

每条出现的数字都带出处：自己测的 → 给协议与方法；引用的 → 给链接。这条与整个工作空间的第一原则一致。

## 2. 人机分工表

| AI 负责（不计入 10h） | 人必须亲自做（10h 全花在这里） |
|---|---|
| 文献摘要、论文精读笔记初稿 | 读论文时的**判断**：哪个设计值得抄 |
| 脚本初稿、标题/封面文案候选 | 出镜口播（中文） |
| 剪辑大纲、字幕、章节切分 | 装配、接线、调试的**手感** |
| 英文 TTS 音轨（YouTube 版） | 试穿、行走、被助力——身体反馈只有你有 |
| 代码：仿真、控制、数据处理 | 物理世界的失败与修复（这也是最有价值的素材） |
| 数据可视化、图表、网站维护 | 审美与取舍的最终拍板 |
| 采购清单比价、BOM 表 | 与供应商/展台工程师的真人交流 |

**边界认知**：AI 干不了装配、试穿、出镜、手感、真实失败。这些是叙事的真实性来源，也是个人 IP 不可替代的部分。反过来，与 AI 协作的过程本身（prompt、争论、AI 犯的错）就是内容素材——录屏随手存。

## 3. 三线总览

- **学**（知识栈 L1–L6，来自调研报告 §2.3）：L1 数学力学 / L2 机械材料 / L3 电子动力 / L4 控制与 AI / L5 生物力学与老年科学 / L6 人因标准合规。优先级：L1、L3 先行（决定能否开工）→ L4（决定能否出活）→ L5（差异化）→ L2、L6（随项目补）。
- **做**（项目链 P0–P3）：P0 仿真复现 → P1 单关节实物（踝优先）→ P2 步态锁相 + 心率实测 → P3 适老特化（坐站/助起，暂缓预算决策）。
- **发**（平台矩阵）：网站（档案库）→ 小红书（练兵+发现流量）→ B站（国内主阵地）→ YouTube（国际，TTS 英文轨）。

## 4. 平台流水线（双轨制）

### 4.1 角色分工

| 平台 | 角色 | 形态 | 更新频率目标 |
|---|---|---|---|
| 静态网站 | 档案库 + 名片 + 对冲单平台风险 | 项目页（方法/数据/复盘）、时间线 | 随里程碑 |
| 小红书 | 高频练笔 + 国内发现流量 | 图文卡片：笔记、踩坑、仿真截图 | 1–2 篇/周 |
| B站 | 国内主阵地 | 5–15 分钟过程流，**中文真人出镜/口播** | 双周一条成片 |
| YouTube | 国际 + 长尾 + 粉丝含金量最高 | 同源内容，**英文 TTS 轨** + 中英字幕 | 与 B站 同步 |

### 4.2 一鱼多吃流程（每次实践触发）

1. 动手时：手机/GoPro 随手拍 + 录屏 AI 协作过程（零额外成本）
2. 当天：踩坑卡片 → 小红书（AI 起草，人定稿）
3. 周末：剪辑过程流 → 中文口播 → B站；同一脚本 → 英文 TTS → YouTube
4. 随时：结论、数据、图纸、代码 → 网站项目页

英文轨注意：TTS 音源与口型无关时以画面+字幕为主；片尾一句诚实说明"本片英文配音由 AI 生成"——人设本身就是 AI 协作，这不是减分项，是人设的一部分。

## 5. 阶段计划（10h/周基准，期限为弹性参考）

> 本节只保留阶段定义与判据门（计划的"宪法"）。任务级 checklist 在 PROGRESS.md §2 任务看板，勾选在那里进行。

| Phase | 主题 | 时间窗 | 阶段判据（门） |
|---|---|---|---|
| 0 | 定位与基建 | 第 1–2 周 | 网站可访问；仿真环境能跑；账号已开且已开口 |
| 1 | 输入期 | 第 1–3 月（与 Phase 0 部分重叠） | 能独立完成受力分析与电机力控；B站已开张 |
| 2 | P1 项目期 | 第 3–6 月 | 单关节实物在人腿上可控输出力矩；B站有一条完整"从零到穿戴"的系列内容 |
| 3 | 实测期 | 第 6–12 月（差异化破圈） | 真人穿戴实测数据公开且方法可复现（基线 vs 助力，原始数据与方法经网站数据页可下载） |
| 4 | 适老特化期 | 12 月+ | IP 一句话能被别人复述；作品集能直接换面试 |

各阶段任务明细见 PROGRESS.md §2。

## 7. 安全与合规红线【不可妥协】

1. **物理安全**：任何真人穿戴实验前，先过假人/沙袋盲测；急停逻辑硬接线（不依赖软件）；电池防爆充电协议；不做骨质疏松高风险人群的任何可能致摔实验。
2. **表达合规**：词库纪律（§1.3）覆盖医疗宣称风险；不宣称防跌倒、不宣称适用失能人群。
3. **平台风险**：核心数据与内容始终有网站档案副本；不开时政议题。
4. **诚信**：AI 生成的部分标注（尤其英文 TTS 与代码）；失败不掩盖——这是人设资产不是负债。
