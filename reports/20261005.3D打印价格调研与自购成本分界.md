## TL;DR

1. **塑料件（FDM/PLA）**：淘宝代打约 **0.2–1.3 元/克**（小件有最低消费 5–40 元），自己打材料成本可低至 **0.01–0.06 元/克**。一台入门机（拓竹 A1 mini 国补后约 976 元）大约在 **打印掉 3–6 公斤料（几十到一百多个淘宝订单的量）** 后回本。
2. **金属件**：自己买机器没有选项（最便宜 SLM 机 16.8 万元/台【引用】），只能外协。国内服务报价：不锈钢 8–15 元/克、钛合金 15–30 元/克【引用】；嘉立创自动化产线实测可低至约 1.6 元/克（316L）【实测】——规模和结构件复杂度对价格影响是数量级的。
3. **外骨骼项目（OpenExo 路线）**：主力是 PLA/PETG 打印箍件与电机座 + 铝铰链 + 碳纤杆，**承力件用「铝合金 CNC + 尼龙碳纤打印」组合即可，金属 3D 打印大概率用不上**。
4. **电烙铁（锡焊）**：装电子部分（电机线、XT30 电池接头、FSR 传感器线）就要用，**建议尽早学**，门槛低（200–300 元焊台入门）。
5. **电焊（弧焊/氩弧焊）**：OpenExo 式结构全是螺栓装配，**大概率永远用不上**；真遇到钢架/铝件焊接，外协钣金厂（嘉立创就有钣金业务）比自购设备合理得多。

## 一、价格怎么算

### 1.1 计价模式总览

| 工艺 | 典型计价方式 | 说明 |
|---|---|---|
| FDM（塑料线材） | 按克 + 起步价 | 主流按克计费，另有按占用打印体积/时长的平台 |
| SLA（光敏树脂） | 按件/按体积 + 起步价 | 小件按件计费常见，起步价低 |
| SLS / MJF（尼龙粉末） | 按件或按材料体积 | 粉末床工艺可嵌套排件，批量单价下降明显 |
| SLM / BJ（金属） | 按克（材料）+ 机器工时 + 后处理 | 报价 = 材料重量 × 单价 + 工时费 + 热处理/线切割（从打印板上切下）等 |

后处理（打磨、喷砂、染色、丝攻）基本都单独计价；多件拼版打印一般能省工时费。

### 1.2 塑料件行情（国内）

## 二、自购打印机 vs 淘宝代打：成本分界点

### 2.1 两边的单价

**自购侧成本**（入门 FDM）：
- 机器：拓竹 A1 mini 官方价 ~1599 元，国补+平台券后 **约 976 元**（拼多多补贴一度 901 元）；A1 ~1799 元【引用：什么值得买《机器被砍到901元，一卷耗材凭什么还卖60》，2026-09；3dprintpricing.pro 2026-09 京东/天猫/官网口径 A1 mini ~1599 / A1 ~1799】。
- 耗材：官方 PLA 约 60 元/kg，第三方平替约 20 元/kg，大促 11.5 元/kg【引用：同上 smzdm 文】。取 20–60 元/kg → **材料 0.02–0.06 元/克**。
- 电费：A1 mini 打印功率 ~57W，10 小时约 0.57 度 ≈ 0.3 元，可忽略【引用：3dprintpricing.pro 功耗数据】。
- 隐藏成本：失败件（新手「炒面」掉盘）、多色换料冲刷废料（「竹屎」）、耗材受潮报废（南方回南天）【引用：同上 smzdm 文】。经验上按材料成本的 1.3–1.5 倍计提比较稳。

**代打侧成本**：0.2–1.3 元/克 + 单件最低消费（约 5–40 元），加运费约 5–15 元/单。

### 2.2 分界点估算

静态回本公式：`回本点 = 机器价 ÷（代打单价 − 自打单价）`

按机器 1000–1600 元、代打 0.5 元/克（淘宝常规价）、自打综合 0.05 元/克：

| 你的打印量 | 结论 |
|---|---|
| < 3 kg（累计） | 淘宝代打更划算，省心免维护 |
| ≈ 3–6 kg | 分界区：约 30–60 个中等订单的量，买机器开始回本 |
| > 6 kg，或单月就有多批迭代件 | 明确自购划算；且省下的**迭代周期时间**比钱更值钱 |

三个使天平倾向「自购」的因素（对你是实情）：
1. **迭代频率**：外骨骼箍件、电机座这类东西改一版尺寸就要重打，代打来回快递 3–7 天，自打 overnight；
2. **隐私**：自研结构件不想上传第三方平台；
3. **学习价值**：你本来就在学制造工艺，机器本身就是教具。

倾向「代打」的因素：尼龙/碳纤/树脂件（需要 SLS/MJF/SLA 工艺，消费机做不了或不值得）、大件（超 256mm）、金属件（别想，外协是唯一选项）。

**结论（推荐组合）**：一台 ~1000–1800 元的拓竹 A1 mini/A1 处理 PLA/PETG/TPU 迭代件；尼龙碳纤、树脂高精度件和一切金属件继续外协。这是当前性价比的最优解，不需要一步到位买设备党的高端机。

## 三、对外骨骼项目的具体建议

OpenExo 的硬件构成（你精读过的整理版：腰带 3D 打印电子/电池仓、铝铰链、碳纤支架/直立杆、3D 打印套筒/箍件、TPU+onyx 应力释放结构、钢缆鲍登传动）：

| 部件 | 建议工艺/材料 | 价格量级 |
|---|---|---|
| 箍件（大腿/小腿/前臂）、电机座、电池仓 | 自打 PLA/PETG（原型）→ 外协 MJF 尼龙（耐用版） | 自打几毛/件；MJF 尼龙外协几十~百余元/件 |
| 衬垫、应力释放件 | TPU（A1 可打，慢） | 材料几十元/kg |
| 铰链、结构接口 | 铝合金 CNC 外协（嘉立创 CNC 起步 $5 量级） | 几十~几百元/件 |
| 直立杆/足板 | 碳纤管/板（淘宝成品切割） | 几十元/根 |
| 传动 | 钢缆 + 链轮 + 滑轮（成品件） | — |

金属 3D 打印在 OpenExo 路线里**没有位置**：它的承力逻辑是「碳纤受拉 + 铝件受压/剪 + 塑料件只做接口和包裹」，这恰好是成本最低的组合。真有一两个局部高应力件（如滑轮支架）需要金属，优先考虑 **CNC 铝合金**（便宜、快、强度各向同性），而不是 SLM。SLM 只在你将来做拓扑优化的轻量化关节壳这类「CNC 做不出来的内部结构」时才值得掏钱，且单价按上面 1.3/1.4 节预算。

## 四、电焊 vs 电烙铁：什么时候需要

这两个是完全不同的技术，别混在一个决策里：

**电烙铁（锡焊）—— 电子电气，很快就会用**
- 用途：电机动力线（AK60 系列的线材焊接）、电池 XT30/T 插头、FSR 传感器线、杜邦线/PCB。
- 时点：**电子动力阶段（你的 l3-电子动力 就是这个节点）就需要**。
- 投入：936/坦头焊台 150–300 元 + 焊锡丝助焊剂几十元，学习曲线一个周末。
- 安全注意：大电流动力线（电机/电池）要焊 + 热缩管，虚接在外骨骼上是安全问题。

**电焊（弧焊/氩弧焊/MIG）—— 结构金属，大概率用不上**
- OpenExo 式结构全是螺栓 + 挤出铝/碳纤装配，**没有焊接工序**。
- 什么时候才需要：自己设计钢制/铝制承重框架（比如以后想做固定式训练架）。铝焊接（氩弧/TIG）手感门槛高，家用场景**外协比自学划算**——嘉立创就有钣金业务（激光切割/折弯/焊接/喷涂），上传图纸直接报价。
- 决策建议：不要为「可能用到」预学电焊。等你图纸里真出现需要焊接的钢结构，把那部分外包，你的时间花在控制和生物力学上更值。

## 七、附：铝 CNC 是什么 + OpenExo 髋构型非电子部分成本拆解（2026-10-05 追加）

### 7.1 铝 CNC 是什么

CNC = Computer Numerical Control，数控机床加工。**铝 CNC** 就是把一整块铝合金（常见 6061、7075）用数控铣床**铣削掉多余材料**，削出设计好的零件——是「减材制造」，和 3D 打印（增材）正好相反。

| | 铝 CNC | 铝 3D 打印（SLM） |
|---|---|---|
| 强度 | 整块铝削出，**各向同性**，数据可靠 | 有层间弱面与内部缺陷可能 |
| 精度 | ±0.05mm 量级 | ±0.3mm，需后加工关键面 |
| 适用 | 承力关节块、铰链、安装座 | 内部随形流道、拓扑优化点阵等铣不出来的形状 |
| 价格 | 按材料去除量+装夹工时计价，小件几十~几百元 | 按克（1.4–15 元/g，见 §1.3/1.4） |

一句话：**能铣出来的就别打印**。OpenExo 的铝件（外展/内收铰链块）官方自己也不做，直接外包 CNC 服务商（美国 UPTIVE），材料 7075 铝。加工文件在官方 wiki → Hip Device Files → `Hip Belt Assembly.zip` → `Part Files for Machining/Aluminum Machining/`（`adAbductionBlockHipSide/LegSide.SLDPRT` 两块）。**注意（2026-10-06 迁移时核实修正）：官方给的是 SolidWorks 零件格式（SLDPRT），不是 STEP**——传嘉立创 CNC 前需先转 STEP（Onshape 免费导入 SLDPRT 后可导出 STEP，或用在线转换器）。

2. **BOM 里 3D 打印件按 Markforged Onyx 内部成本计**（$294，Onyx 是 Markforged 专用碳纤尼龙线材）。你没有 Markforged，可用普通 FDM 打 PA12-CF/PETG 替代（自己 A1 + 碳纤尼龙线材），或外协 JLC 的 PA12-CF（§1.4 实测 79.5cm³ 件 ¥183）。大腿箍这种贴身件建议耐用版外协尼龙。
3. BOM 不含运费和工具（钻模、钻头、丝锥等），也不含你后续做踝/肘构型的鲍登传动件（钢缆、护套、滑轮、链轮），那部分官方单独成册（Bowden Cable Assembly）。

### 7.3 结合上一节的决策建议

- 第一台髋构型的机械部分预算按 **¥2,000–3,500** 留（国内渠道，含 2–3 轮迭代重打）；电子部分另计约 $883（AK60 电机×2 占 $598，是大头，CubeMars 国内代理可询价）。
