## TL;DR

**问题一：国内有没有做这个方向的企业？**
有，而且已经形成图谱，但分布极不均匀：
1. **行走助力**（外骨骼）打得最热：医疗型约 17 万元级、消费型从 ¥15,999（海尔 W3）一路杀到 **¥2,500（程天 EasyGo）、¥9,800（智元研究院踏山 TK1000，官方明说专为下肢肌力衰退老年人设计）**。极壳、傲鲨、迈步、火箭院「智行」等都在场。
2. **室内起居自主化**（起身借力、床椅转移、扶持行走）几乎是智能硬件真空带：现状是机械扶手马桶、¥100–2400 的白牌移位机、助起沙发——没有头部智能品牌。这正是你说的「让老人自己来」的用武之地，也是商业上最难啃的一段。
3. **替代护理端**（替老人干）反而落地最快：如厕机器人（跃伴「小伴」）、二便护理（海尔天悦、作为科技）、洗浴机器人（戴恩）——因为买单的是子女/机构，痛点最尖锐。
4. 政策面本周刚发生重大变化（详见 §1.6）：国家医保局《全民医疗保障「十五五」规划》首次把「智能外骨骼等智能化设备」写进长护险蓝图；14 部门三年行动方案同步推进。支付通道正在打开，比两天前的认知更进一步。

**问题二：两条路怎么走、需要什么知识？**
两条路不是二选一，DIY 作品集本身就是进企业的敲门砖。本轮抓取的真实招聘 JD 显示市场要求集中在六层知识栈：数学力学 → 机械材料 → 电子动力 → 控制与 AI（步态识别、阻抗/导纳控制、意图预测）→ 生物力学与老年医学 → 人因/标准/合规。今天开工是历史性有利时机：**OpenExo（Science Robotics 2025，全软硬件开源模块化外骨骼）和 Open Source Leg（Nature Biomedical Engineering 2020）已把领域入门成本降到「一个人 + 几万元」的水平**。§2.5 给出一份「假如大学开这个专业」的完整培养大纲设计稿。

## 一、国内「老年自主起居」企业图谱

### 1.0 先校准问题框架：两类产品，别混谈

延续前篇的分类法，但按你的主张再进一步：产品对老年人的姿态有两种——

| | **自立支援型**（让老人自己来） | **替代护理型**（替老人干） |
|---|---|---|
| 典型叙事 | 重获掌控感、尊严、延缓失能 | 减轻照护者负担、「一人失能全家失衡」 |
| 使用者 | 老人本人穿戴/操作 | 护士/家属操作，老人是被作用对象 |
| 行走 | 消费级助力外骨骼 | —— |
| 起身 | 助起扶手马桶、助起沙发（低智能） | 移位机（吊臂吊带，护工操作） |
| 如厕 | 扶手借力、坐便升高 | 二便护理机器人、纸尿裤传感 |
| 出行 | 助行器、动力轮椅 | AI 智驾轮椅（跟随导航，仍属乘用） |
| 主要买方 | 尚有支付意愿的活跃老人及子女 | 失能者家庭、养老机构、（未来的）长护险 |

来源为本轮老博会报道归纳【推断，分类框架是我的整理】。你的方向选前者——这在日本介护体系里叫「自立支援」，已被验证为政策正确（日本 2005 年《介护保险法》修订后全面转向该理念；此处为训练数据背景，未在本轮重查，标注存疑），但在中国的产品供给恰恰最少。

### 1.2 坐站与移乘层：最大的真空带

这是你说的「起床、站起来」环节，本轮盘点结果：

- **智能化产品几乎缺席**。真实供给是：海尔「天悦双助扶手马桶」（两侧扶手借力、脚感冲水、助便洗）、助起沙发——本质是人体工学五金件【新华网全文已读】。
- **移位机**（把卧床者吊起来转移到轮椅/浴缸）：电商白牌主导，淘宝带常见价 ¥100–2380【快照】。行业数据显示这是失能照护刚需，但厂商高度分散、无头部智能玩家【推断，基于检索所见均为通用 listing 而非品牌发布会】。
- 海尔失能方案里出现「步入式浴缸 + 专用移位机」组合——即连龙头企业的解法也是「物理升降」，而非智能助力。

**判断**：这一层的空白是真实的，但你也要看到它空白的理由——使用者是最没有支付能力和支付意愿的重度失能前期人群，且技术难点（扶持中的人体负载、跌倒责任界定）恰好落在消费级与医疗级的监管夹缝里【推断】。

### 1.5 供给侧结论：把上一份报告的判断闭环

前篇说消费级外骨骼「适合还能走的老人省力」。现在加上两层：

1. 老人在失去行走能力**之前**，通常先经历「起坐困难」数年——那段时期的自立支援产品在中国基本停留在五金件水平；
2. 产品热区（户外徒步助力）与需求热区（居家起坐扶持）错位，因为前者有钱赚（景区租赁、驴友溢价），后者缺支付方。

这解释了为什么你的直觉方向「自主起居」同时成立又没人做好：**成立**是因为需求结构真实且即将被政策喂饱（见下节），**没人做好**是因为它需要跨医疗器械边界、渠道走社区/物业而非电商、且客单价撑不起硬件创业的成本——直到长护险开始付钱。

### 1.6 本轮最重要的增量：支付政策变化（2026-08）

以下全部来自北京商报（胡永新）2026-08-20 报道，新浪财经全文已读（https://finance.sina.cn/2026-08-20/detail-ininysmm8606035.d.html ）：

- 国家医保局近日印发《全民医疗保障「十五五」规划》，提出：「推动长期护理服务资源合理布局……**促进智能外骨骼等智能化设备在长期照护领域应用**」；「十五五」期间长护险制度覆盖**所有统筹地区**。长护险现有参保规模已达 **3.2 亿人**（社保「第六险」，2016 年启动试点）。
- 2026 年 5 月民政部部际联席会议：推动符合条件的康复辅助器具适时纳入医保、工伤、长护险支付范围；2026 年 7 月民政部、国家医保局等 **14 部门**联合印发《康复辅助器具产业扩能提质三年行动方案（2026—2028 年）》：研究探索将长期护理相关智能化服务和支持性辅助器具纳入长护险支付范围。
- 现状（业内专家龙格，众托帮）：北京、上海、江苏等**十余省份已将医用外骨骼康复训练服务费**（注意：是服务费，不是设备）按医保乙类或长护险试点报销 50%–70%；消费级助行设备尚未进目录。
- 「四重卡」：医用设备单台 10 万+ 家庭买不起；无长护专用编码与疗效计价；消费级无养老防跌安全标准；居家运维与数据回传缺失。
- 落地节奏预测：2026–2028 按「医院康复项目 → 社区租赁服务包 → 居家辅具租赁」三步走，医用级快于消费级；模式主流意见是「租 > 买」。
- 市场量级参照：IDC 数据 2025 年中国医疗康复外骨骼机器人市场规模约 14.2 亿元、出货约 3200 台（对比东财 AI 稿的「全部外骨骼 2.6 万台/16 亿元」，两口径并列，差距即消费级市场规模：确实还很小）。

对你的意义：中国正在走日本 2016 年的老路（把助力设备接进长期照护保险），时间窗口大约 2–4 年。谁能在标准制定期（消费级防跌安全标准缺失）入场参与标准建设，谁就站到 Rental-economy 的上游【推断】。

## 二、能力建设：DIY 博主与进企业怎么选、学什么

### 2.1 结论先行

1. **两条路不是岔路口，是一个漏斗的两端**：从单关节开源平台开始攒作品集 → 过程发布成为内容 → 用作品集应聘该赛道头部公司（或反向发现：产品真体验过了，自己创业的点反而更清楚）。国内已有「技术 UP 主 → 创始团队」的成功路径先例（稚晖君 B 站起步至智元机器人联创，属公认背景事实）。
2. 这一行真正的稀缺能力不是「会造」，而是「造出来的东西**老人愿意天天穿**」。所以知识栈里被一般工程师最忽视的两层——生物力学实测与老年用户研究——恰恰是你的差异化机会（前篇田丰「竞争核心已变成老人愿不愿意长期穿」）。
3. 历史时机站在 DIY 一边：OpenExo 把 NIH 级硬件设计全套开源，mjbots moteus 等高性能驱动单元散件可购——**五年前这套东西只有实验室有**。

### 2.3 六层知识栈（培养大纲的最小内核）

| 层 | 内容 | 判据（学完你应该能…） |
|---|---|---|
| L1 数学与力学 | 微积分/线代/概率统计、理论力学、材料力学、机构运动学动力学 | 对一个髋关节助力机构做受力分析与电机扭矩估算 |
| L2 机械与材料 | 机械设计、传动（谐波/行星/连杆）、铝合金/碳纤维工艺、轻量化拓扑 | 出一套可加工的单关节结构件图纸，知道良率与成本的约束在哪 |
| L3 电子与动力 | BLDC 选型、FOC 驱动、电池/BMS、IMU/FSR/sEMG 传感、嵌入式（STM32/ESP32） | 用 moteus 或 ODrive 驱动一个力矩透明可力的关节 |
| L4 控制与 AI | 经典控制 → 阻抗/导纳控制、步态相位检测（IMU 阈值法→HMM→学习法）、human-in-the-loop 助力优化 | 让单关节外骨骼在人走路时输出与步态相位锁相的助力矩 |
| L5 生物力学与老年科学 | 步态分析（时空参数/TUG/6 分钟步行）、代谢成本概念、衰老生理与常见病症（关节炎/中风后遗/肌少症）对控制的约束 | 设计一份给真老人的测试 protocol 并预判伦理风险 |
| L6 人因/合规/伦理 | 穿脱时间、皮肤压力、跌倒后果分析；ISO 13482 个人护理机器人、ASTM F48 外骨骼委员会、国标《外骨骼机器人 人机交互安全风险评估方法》（前篇已核实立项）、NMPA 二类边界；长护险与辅具支付体系常识 | 能说出你的产品为什么不需要 NMPA 证（或必须需要） |

L4/L5 是外骨骼区别于一般机电产品的核心；L6 是这个赛道区别于一般机器人赛道的核心。

### 2.4 DIY 博主路径的项目序列

以两个已核实的开源基石为起点：

- **OpenExo**（NIH 支持，Science Robotics 2025-06-25 正刊，https://www.science.org/doi/10.1126/scirobotics.adt1591 ）：软件、硬件、电子、控制的**全套模块化开源**外骨骼框架，支持髋/膝/踝多种构型；执行器选用 CubeMars AK 系列（官网有合作页 https://www.cubemars.com/openexo-modular-exoskeleton-with-ak-robotic-actuators.html ）。作者明确目标是降低开发与教学门槛——这就是给你准备的。
- **Open Source Leg（OSL）**（密歇根大学 Neurobionics Lab/Rouse + 芝加哥 Shirley Ryan AbilityLab/Hargrove，Nature Biomedical Engineering 2020-10 正文 https://www.nature.com/articles/s41551-020-00619-3 ）：膝踝假肢开源平台，文档化程度高，是学「关节如何像人一样发力与顺从」的最佳教材。

建议序列【推断，为我的设计建议】：

- **P0（1–2 月）**：跑通 OpenExo / OSL 仿真 + 读透论文的控制部分。产出：解析视频两支。
- **P1（3–5 月）**：复现单关节（踝优先——便宜、风险低、文献最多，前篇 2023 JNER 研究 −25% 能量成本就是踝外骨骼做的）。预算量级：国产 AK 类执行器 ×1 + 结构件 + 传感 ≈ 2–4 万元【推断】。
- **P2（6–12 月）**：加步态相位检测，做出「零助力锁相」，再用心率（腕带/H10 心率带，全平台可购）做自己的代谢代理指标小实验——这就是第一条破圈内容：《我用 3 万元复现了 ScienceRobotics 的外骨骼，实测省了多少力气》。测量范式直接抄学术（TUG、6MWT、n 人次重复），从此你发的每个数据都有出处。
- **P3（12 月+）**：转向适老特化：坐站转移助力或「助起扶手 + 助力」装置（对应 §1.2 空白），找养老驿站/社区合作招募志愿者试穿——把 L5/L6 变成你的内容壁垒。
- 安全红线（务必内化）：任何真人助力实验前置盲测（假人/沙袋模拟）、急停逻辑、电池防爆充协议；不给骨质疏松高风险人群做任何可能致摔的助力臂实验。这条既是伦理也是你账号不塌房的前提。

内容侧判断：中文世界的技术评测多停留在「上手开箱」，**过程向硬核工程流 + 学术严谨度量**是空位【推断】；对标不是科技区顶流流量，而是其转化路径（影响力 → 求职 offer / 社群 / 未来众筹预售）。

### 2.5 进企业路径的战术

- 目标公司按 §1 分层列一份清单即可（行走助力：程天/智元研究院/极壳/傲鲨/迈步/海尔；综合适老：海尔智慧康养/美的系；康养机器人：傅利叶/跃伴/作为科技等）。某一家能不能让你学到「老人长期穿戴」的完整方法论，取决于其是否有线下门店/机构渠道（海尔 200+ 体验点是天然课堂，前篇数据）。
- 岗位选择顺序建议：**测试/临床或用户研究岗 > 算法岗 > 机械岗**——理由：这个行业的瓶颈在前者，最容易被简历刷掉的也是前者（多数候选人是纯机械/纯算法出身）【推断】。
- 展会情报节奏：上海老博会（每年 6 月）→ 世界机器人大会·北京（8 月）→ WAIC（7 月）→ CES（1 月）。去三次展、和展台工程师聊三小时，胜过看十份行研报告。
- 投递材料映射：把你 P0–P3 每个 milestone 换算成 JD 语言（§2.2 词表），一条作品配一条能力声明。

### 2.6 假如大学开设「适老助力外骨骼」专业：培养大纲设计稿

现实基座（均已核实）：教育部 2019 年批准上海理工大学设「**康复工程**」本科专业（代码 **082604T**，生物医学工程类；该校 2006 年已办国内第一个康复工程本科方向，挂靠上海康复器械工程技术研究中心 https://re.usst.edu.cn/12563/list.htm ）；「**假肢矫形工程**」（082602T）已在 6 所本科院校开设【SciEngine 论文 https://www.sciengine.com/SSV/doi/10.1360/SSV-2022-0148 】。也就是说，这个设想的专业 = 康复工程 ∩ 机器人工程 ∩ 老年医学，并非空想，只是尚无人把「老年日常起居助力」设为专业主线。以下大纲为我的设计稿【推断，供讨论】：

**本科四年（工学学士，生物医学工程类，150 学分制示例）**

| 阶段 | 课程组 | 课程 |
|---|---|---|
| 大一 | 数学物理 + 工程通识 | 高等数学、线性代数、概率统计、大学物理、程序设计（C++/Python 双轨）、工程制图与 CAD、金工实习 |
| 大二 | 力学与机电基础 | 理论力学、材料力学、机械原理、机械设计、电工电子技术、控制工程基础、传感器与检测技术、嵌入式系统 |
| 大二–大三 | 专业基础（本专业特色课组） | **人体解剖与生理学概论、生物力学、人体运动学与步态分析、老年医学导论（含衰老生物学、常见病谱）** |
| 大三 | 专业核心 | **外骨骼与可穿戴机器人设计**（传动、柔性驱动、人机接口）、机器人学（运动学/动力学）、信号处理与 sEMG 解码、机器学习与意图识别、阻抗/导纳与柔顺控制 |
| 大三–大四 | 人因与社会 | 人机工程与适老化设计（通用设计原则）、辅助技术国际标准与法规（ISO 13482/ASTM F48/NMPA/FDA/CE）、康复辅具产业与支付体系（医保/长护险个案研读）、老年心理学与伦理 |
| 贯穿 | 实践链 | 认识实习（医院康复科/养老机构各 ≥2 周，必修）→ 单片机课设 → 外骨骼课程群 capstone（一年级一组，含**至少 5 名老年真实用户的迭代测试**，伦理审查流程演练）→ 企业实习 → 毕业设计 |

**研究生段（硕士，三个 Track）**
1. 器械方向：轻量化结构/柔性外骨骼/软体助力服、能量回收与续航优化；
2. 算法方向：连续相位估计与自适应助力优化（HIL）、sEMG/IMU 多模态融合、个性化参数在线整定；
3. 临床与系统方向：临床试验设计（GCP 基础）、ADL 终点与卫生经济学评价、租赁与长护险商业模式验证。

**这份大纲与普通机器人专业的 7 个差异点**（也是各高校若真要开此专业的验收要点）①医院/养老院双见习必修；②老年医学是专业课不是选修；③capstone 强制老年真实用户闭环；④伦理与隐私单独成课；⑤标准与注册实务成课；⑥支付体系（长护险）写入培养目标；⑦评估指标教 ADL/TUG/6MWT 而非只是精度与负载。——换句话说：**大纲的灵魂在 L5/L6**，这同样是你自学的重心分配依据。

## 三、给你 30/90 天的动作清单

**30 天**
1. 通读 OpenExo 论文全文 + 对应 GitHub 仓库（搜 OpenExo + exoskeleton）；装好 ROS2 与 PyBullet/MuJoCo 任一仿真环境。
2. 下单一套心率带 + 秒表，对自己完成一次 TUG/6 分钟步行基线测试并写成第一篇方法文章（练习「数据带出处」的表达习惯）。
3. 盘点资金上限，决定 P1 做踝还是髋（踝推荐，理由见 §2.4）。

**90 天**
4. 完成 OpenExo 单关节件的采购清单与报价（CubeMars AK 系列国产可得性直接问经销商），产出发货第一支复现视频。
5. 参加一次行业活动凑脸熟（近期最近的一场是年底各地康养展/明年 1 月 CES）；关注上海老博会报名节点。
6. 简历初稿按 §2.2 词表改写，投出第一批「测试/用户研究」岗探水温——即使你最终想创业，面试反馈是最好的行业教材。
