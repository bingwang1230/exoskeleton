# 仿真环境安装方案（macOS arm64 · MuJoCo 主推）

> AI 初稿 2026-08-30，机器实测前置条件：Apple Silicon（arm64）+ macOS 26.2 + Homebrew Python 3.14.6 + uv 0.12.3 已装。
> 对应周计划「仿真环境装好并跑通官方示例」，预估人时 ~1h。
> ⚠️ 前提认知（见精读笔记 §6）：OpenExo 官方仓库无仿真组件，本环境是 P0 自建踝模型的地基，不是「跑作者的仿真」。

## 0. 为什么是 MuJoCo 而不是 PyBullet

| 维度 | MuJoCo（推荐） | PyBullet |
|---|---|---|
| 维护 | DeepMind 官方维护，2021 起免费，更新活跃 | 社区维护，更新缓慢 |
| macOS ARM | 原生轮子，pip 即装即用 | 需本机编译源码（首次 5–15 min，需 Xcode CLT，偶发编译失败） |
| 生态 | dm_control / Robosuite / MJX（GPU 加速）都基于它 | 独立 |
| 与本项目的契合 | 关节力矩/接触动力学质量高，适合外骨骼关节建模 | 够用但老 |

结论：**主推 MuJoCo**；PyBullet 仅当 MuJoCo 在 3.12 下意外不可用时作备选。

## 0.5 装在哪台机器（双机注记，2026-08-30）

基础 MuJoCo 验证（本周这项）任一机器可跑，mini 方便就 mini；后续 MJX（GPU 并行）/批量优化/重渲染等重负载默认上 MBP（M4 Max/128G），见 AGENTS.md §9。两机各自 clone 本仓库，开工前 `git pull`。

## 1. 一个坑：系统 Python 是 3.14

MuJoCo 对最新 CPython 的轮子发布通常滞后数月，3.14 有概率没有现成轮子。**解法：用 uv 建 Python 3.12 虚拟环境**（uv 自动下载管理 3.12，不动系统 Python，一条命令）。

## 2. 安装步骤（逐条复制执行）

```bash
# 1) 建目录（将来 P0 仿真仓库的种子，先临时放 sandbox）
mkdir -p ~/sandbox/exo-sim && cd ~/sandbox/exo-sim

# 2) 建 3.12 虚拟环境（uv 已装 0.12.3 ✅）
uv venv --python 3.12

# 3) 激活 + 装 MuJoCo
source .venv/bin/activate
uv pip install mujoco

# 4) 验证装好了
python -c "import mujoco; print('MuJoCo', mujoco.__version__)"
```

预期：第 4 步打印版本号即成功。若第 3 步报「无匹配轮子」，降级 `uv venv --python 3.11` 重来（仍是同套命令）。

## 3. 跑通第一个模型（= 周计划的「官方示例」验收）

把下面存成 `leg0.xml`（一个带踝关节弹簧的摆腿模型，MJCF 官方格式）：

```xml
<mujoco model="leg0">
  <option timestep="0.002"/>
  <worldbody>
    <geom name="floor" type="plane" size="5 5 .1" rgba=".9 .9 .9 1"/>
    <body name="thigh" pos="0 0 0.9">
      <joint name="hip" type="hinge" axis="0 1 0" damping="0.1"/>
      <geom type="capsule" fromto="0 0 0 0 0 -0.45" size="0.05" mass="5"/>
      <body name="foot" pos="0 0 -0.45">
        <joint name="ankle" type="hinge" axis="0 1 0" stiffness="50" damping="1"/>
        <geom type="capsule" fromto="0 0 0 0.12 0 -0.05" size="0.03" mass="1"/>
      </body>
    </body>
  </worldbody>
</mujoco>
```

```bash
# 图形界面打开（会弹出一个 3D 窗口，可以拖动视角）
python -m mujoco.viewer --mjcf=leg0.xml
```

**验收标准**：3D 窗口弹出、腿在重力下摆动、踝关节因弹簧回弹。做到这一步，周计划该项可勾。
