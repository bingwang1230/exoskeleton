## 1. 一句话

一套**软/电/硬/控全开源的模块化无缆外骨骼框架**：一条腰带上快速换装髋/踝/肘构型，Teensy 微控制器 + CAN 总线驱动 CubeMars AK 系列电机，作者明说目标是把入门门槛降到「非专家也能复现」。

## 3. 四层架构拆解

**软件（modularity 的核心贡献）**：层级 = 整体 → 左右侧 → 关节 → 控制器/传感器/电机。控制器定义为抽象类，一控多关节不重复定义。构型信息从 SD 卡文件读取——换硬件不用重编译。仓库实际内容：`ExoCode`（固件）、`Libraries`、`Python_GUI`、`Android_App`/`IOS_App`、`SDCard`、`Documentation`（readthedocs）。

**电子**：单 PCB、最多双侧 2 关节，刻意做得比 FlexSEA 简单（少 PCB 互联），面向「生物力学背景的人也能焊/改」。电机生态绑 CubeMars AK 系列（南昌）——**国产可得性对我们是利好**。CAN 总线统一协议，换电机型号（AK60→AK80）不动架构。

**硬件**：全部构型共用腰带来集成；髋=直驱开环（低成本入门位）；踝=鲍登线远端驱动（腰上电机→钢缆→踝滑轮→碳板），刻意减少远端质量与侧向突出；多尺寸足板/小腿箍快换。髋&踝可同带组合（负重行走验证过）。

**控制**：低层（电机电流/力矩环，hip 用开环、ankle/elbow 用带串联力矩传感的闭环）+ 高层（角度传感器参与）。⚠️高层控制器具体策略（自适应/比例/步态触发？）在本体写得很略，细节可能在补充材料或 wiki——**这是批注时值得标记「要深挖」的第一处**。

## 4. 验证链条（论文的说服结构，值得学）

1. 台架阶跃（响应速度）→ 2. 台架/穿戴力矩跟踪（~7% 误差）→ 3. 续航与热（35 min，电池先限）→ 4. 人体小样本（n=1–2，代谢/步态）。
对我们 P2 的启示：**测量方法学链条可以直接抄**——阶跃、跟踪、续航、代谢四层，每层有明确指标。

## 5. 对我们（P1 踝复现）的直接启示 ⚠️批注重点

- **值得抄**：鲍登线+踝滑轮的远端驱动布局（减远端质量）；4.5:1 滑轮减速；SD 卡配置化；CAN + AK 系列电机选型；碳板插普通鞋的用户接口。
- **成本锚点**：髋 ~$2–2.5k，踝构型成本论文未直接给 ⚠️（可能在 wiki BOM）——询价时以此量级 sanity check。
- **安全相关**：热限 100°C、电池 3.7V/cell 停机——这两条应进我们的台架红线（对照三线计划 §7）。

## 6. 重要发现：官方仓库无仿真组件

`naubiomech/OpenExo` 是**嵌入式为主**的仓库（Teensy 固件 + 手机 App + Python GUI + 文档），**没有 MuJoCo/PyBullet 仿真**。
→ 含义修正：周计划「仿真环境跑通官方示例」只能是通用引擎的示例；「P0 仿真复现 OpenExo」实际含义应是**我们自己把踝构型建模进引擎**（参数照论文抄：4.5:1、28 Nm 目标力矩、足板质量特性），而不是跑作者现成的仿真。⚠️这个理解请确认——它决定 P0 的产出定义（也影响「解析视频」的内容设计）。
