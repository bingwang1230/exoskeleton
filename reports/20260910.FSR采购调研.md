## 2. FSR 是什么，OpenExo 怎么用的（对齐复现参数）

力敏电阻：两层聚合物薄膜，压得越重电阻越小（无载 >10MΩ → 满载约 2kΩ），两线器件，一颗分压电阻即可读模拟量。

OpenExo 论文中的用法（正文未写具体型号，补充材料 BOM 未随 PDF 附上）：

| 工位 | 位置 | 用途 |
|---|---|---|
| 跟 FSR + 趾 FSR | 足底鞋垫下（双侧） | 步态相位：跟击/趾离 → 步态周期与相位 |
| 前足 FSR | 第一跖骨头下（踝构型，碳板上） | PJMC：归一化 FSR → 估计生物踝力矩，按比例缩放助力 |
| 手部 FSR | 中/环/小指并联 + 拇指基（肘构型） | 握持触发（阈值 0-1） |

关键设计哲学（learn 笔记 ch05）：**「FSR 信形状不信绝对值」**——输出连续但精度差，论文只用归一化值与阈值化；每次穿戴做量程式校准吸收贴合差异。我们第一版实测（脚法波形/重心转移）同样是形状分析（上升沿斜率、渐变性），与这个哲学匹配。

## 4. 购买注意事项（按踩坑概率排序）

1. **型号建议改 FSR 402 为主（AI 设定，待确认）**：决策原文写 FSR 400（Ø5mm 小面积），但足底/鞋垫场景 Ø13mm 的 402 容错高、DIY 资料（Adafruit/Sparkfun 教程）全是 402、淘宝现货也以 402 为主。论文只说 "small FSRs"，未必是 400 这个具体型号。
2. **量程饱和是最大坑**：官方量程到 20N（≈2kgf）。**脚底单点受力（哪怕只踮脚）通常远超 20N**——传感器不会立刻坏（静载 2.5kg/24h 漂移 <5%），但输出会顶格，绝对力值没意义。对策：①我们本来就做形状/相对量分析（与 OpenExo 归一化哲学一致）；②要绝对力值时用传力垫（橡胶/EVA 小凸台）限制传入力 + 砝码标定；③别用 FSR 做精确测力——那是力矩传感器（应变片）的活。
3. **淘宝价签口径**：兼容款标「100g–10kg」是厂家口径（≈1–100N），与 Interlink 官方 20N 灵敏度范围不一致——大概率是「能承受+有输出」与「有分辨率的量程」之别。按官方保守口径预期。
4. **原装 vs 兼容**：原装批次一致性好（±6% 件间）；国产兼容片个体差异大 → **每片单独标定**（矿泉水瓶 + 电子秤就能做，¥0）。第一版实测 + 内容拍摄用兼容片足够；Phase 2 复现上原装。
5. **买「已焊引线/带杜邦座」的版本**：FSR 尾端是薄膜焊盘/ ZIF 触点，自己焊容易烫坏；鞋垫走线选**长尾**（56mm 或更长定制）。
6. **别买带放大电路的模块板**：板厚塞不进鞋垫；裸片 + 一颗 10kΩ 电阻分压就是标准读法。
7. **立创商城无此品类**（只有 MEMS 气压传感器，本次实查）；DigiKey 官网被 Cloudflare 拦（未核实原价，海外直购物流也等不起）——国内主渠道就是淘宝。

## 9. 安装与数据链路设计（2026-09-10 会话补充：用户硬件零基础，攀岩鞋无鞋垫）

### 9.1 电路常识十分钟版（本单用到的全部）

- 三词：电压 V（水压差）/ 电流 A（水流）/ 电阻 Ω（管粗细）；欧姆定律 V=I×R 是唯一公式。
- FSR = 会变的电阻（无载 >10MΩ → 重压约 2kΩ），两线无极性。
- 分压：`3.3V —[FSR]—●—[10kΩ]—GND`，中点电压 = 3.3 × 10k/(R_FSR+10k)。没压 ≈0V、10kΩ→1.65V、2kΩ→2.75V（压力越大电压越高）。
- ADC：ESP32 内置 12 位，0–3.3V → 0–4095，每秒可读千次。
- 面包板：凹槽左右分家；每半排 5 孔互通；两侧电源轨整列竖通；免焊。

### 9.2 数据链路（V=版本）

```
[压力] → [FSR] →(2线)→ [面包板分压] →(1信号线)→ [ESP32 ADC] → USB/WiFi → [电脑 Python 实时曲线]
```

回传两模式：USB 串口（桌面/地面版，100Hz 足够——脚部动作几 Hz、上升沿几十 ms；体重秤几 Hz 干不了）；WiFi（上墙版，ESP32 自建热点，无需岩馆网络，每秒几 KB）。固件与电脑端脚本 AI 代写，人只插线。

### 9.3 安装三版（由易到难）

1. **V1 桌面版（到货第 1 天）**：面包板 + 手按/脚踩，USB 直连看波形。目标：链路全通。
2. **V2 普通运动鞋版（S-008 重心转移主力）**：普通鞋有鞋垫——掀开，前掌 1 片 + 脚跟 1 片，线从鞋口引出。分屏拍摄「压力曲线+脚同框」（B站首条候选地面版素材）。
3. **V3 攀岩鞋版（脚法量化）**：攀岩鞋无鞋垫、内里紧——**贴外底**。分层（从鞋底往外）：FSR 主体（双面胶贴外底前掌内侧、大脚趾球正下方/edging 受力点）→ EVA 泡棉 2–3mm（点接触摊成面 + 保护）→ 布基胶带（耐磨）。引线沿鞋底边缘绕鞋帮至脚踝，每 2cm 胶带固定，转弯留应力释放弯。**第一版不上墙**：岩点/木块放地上踩「轻放 vs 砸放」，USB 直连；上墙无线版（ESP32+充电宝绑踝/挂安全带）为第二期。

### 9.4 量程饱和的诚实边界（对外口径也按此）

官方量程 ~0.2–20N（≈2kgf）：踮脚单点受力 >50kg 常见 → 读数顶格，**绝对公斤数不可读、精度不可指望（迟滞 ±10%）**。但「贴脚 vs 砸脚」的分野在触地最初几十毫秒的压力爬升段（0→2kg 在上升沿上），缓坡 vs 陡坡曲线形状可辨——与 OpenExo「FSR 信形状不信绝对值」同路。内容口径：测的是「放脚的温柔程度」，不是力的大小。
