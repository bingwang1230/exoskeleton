# exoskeleton｜AI 协作造外骨骼

「AI 时代，一个人就能搞外骨骼」——一个人 + AI，把论文里的助力外骨骼真的造出来、穿上、量出数据，全过程公开。

- 人类先读：`docs/需求文档.md`（这是什么、不做什么）
- agent 先读：`AGENTS.md`（工作协议：目录/铁律/下一步协议/提醒协议）
- 当前进度：`PROGRESS.md`
- 为什么是现在这样：`docs/决策记录.md`

## 文档地图

| 文件 | 角色 |
|---|---|
| AGENTS.md | agent 工作协议 |
| PROGRESS.md | 活的看板：快照/阶段门/任务看板/本周计划/学习排期/周记 |
| docs/需求文档.md | 章程：定义/交付物/不做清单/约束/风险/待确认 |
| docs/三线计划.md | 计划：叙事词库/人机分工/平台流水线/阶段判据门 |
| docs/决策记录.md | 决策日志（追加式，最新在上） |
| reports/ | 项目调研报告 |
| learn/ | 学科学习（L1–L6，每科一个子目录） |
