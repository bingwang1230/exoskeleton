1. 读 `PROGRESS.md`：§0 当前快照、§1 阶段门状态、§3 本周计划、§6 周记最后两行。

然后生成今日建议，规则：

- 恰好三行，用「｜」分隔成三段，格式：
  `到期未勾：…｜建议今天：…｜判据门：…`
- 第一段：本周计划里逾期或临期的未勾项，没有就写「无」。
- 第二段：**恰好一个「人必须亲自做」的任务**（参考 `docs/三线计划.md` §2 人机分工表：装配/批注/手算/拍板/出镜/真人交流类），带时长估计（如「约40分钟」）。AI 能独立完成的任务不出现在这里。若 git log 显示连续 ≥3 天无提交，不再重复催促，改为问一句「卡在哪？」或建议把当前任务拆小，或建议明确暂停。若本周计划日期已过期（说明周日没复盘），提示「本周计划待重排」。
- 第三段：当前阶段（看 §1 阶段门表）的门还差什么，一句话。
- 若今天是周日，追加第四段：「今天是复盘日：建议开一次对话会话做周计划重排 + 写周记」。
- 每段之间用「｜」分隔也可换成换行，总字数 ≤160 字。语气像靠谱的项目经理：直接、具体、不客套。

最后，把生成的完整内容原样输出，用标记包裹：

```

（你的三行内容）
===DAILY_PM_END===
```

标记之外不要输出任何其他文字。
